# Generated movement plus supported mechanics

Four predeclared fresh4x4 generator seeds, existing simple playability filters,
hybrid movement and a fixed supported semantic recombination. This is synthetic
interface development, not a strength sample or a general performance claim.

Index members are extracted/rehashed. Recover into an isolated checkout at
2f40bd85911eb0c70dd91ee3047f385ebc373f46, restore relative paths and existing
Python/Native dependencies. `transfer.py` reconstructs all four rules, follows
the deterministic twelve-ply coverage route and compares bounded Core references
with cold public search repeats. `event_frontiers.py` covers every actually
observed active-slot, expiry and guarded-drop event on those routes, comparing
Core/Native public legality under one fixed evaluator. Producers reject existing
outputs; use a fresh extraction. `package.py` reconstructs compact summaries.

Full rule definitions, routes, hands, auxiliary state, histories, PVs and costs
are retained. No user/private inputs, Slack/accounts, credentials or workflow
state are included. Guards/expiry occur in only part of the four-seed routes;
zeros remain. Final12ply comparisons alone would not cover active expiry slots,
which is why the separate event-frontier comparison is retained. No product or
workflow setting changes, human-price fitting, NNUE or extra workers.
