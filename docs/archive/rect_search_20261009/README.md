failures (derived summaries), corrected q0/q2 runs, fixtures and regression logs.
Absolute-path traceback originals remain private locally. effect-transfer.zip
and its index add actual temporal/compound effects and real session histories.
Extract only into an isolated checkout and check every indexed SHA-256. Restore
the shared rect_probe.py/fixture dependencies; never overlay live state.

request can select Core when compilation is unsupported; it is not evidence
for Native rectangle kernels. The default square price builder is not extended.
evaluation_profile=None with an override is the explicit public contract.

the capability claim/test was corrected. One effect producer called nonexistent
GameSession.apply before saving output, then used submit and actual replay.

the incomplete zip stays local, and the successful archive was extracted/hashed.

of the final typed-Native case;49 final relevant tests include it.

endpoint API, not another search cohort. To run the producer, place it beside
