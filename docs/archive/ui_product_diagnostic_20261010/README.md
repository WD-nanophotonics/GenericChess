# UI product diagnostic recovery

See ../../research/UI_PRODUCT_DIAGNOSTIC.md and its data index. evidence.zip
contains reviewed Agent-produced source, results, declarations and failures.
Exact member hashes plus original local hashes are recorded; JSON device paths
are normalized. No user-authored UI export, pinned dependency tree, raw Slack,
account records, credentials or raw binary profiler output is included.

Recover selected members into an isolated directory, not over the live tree.
The failed engine-owned/amortized trigger prototypes require the pre-integration
sandbox baseline ec78e95e4500f5a997edd46247d6bf63a017a36a. Never import them into
production; the final compiled-owned implementation is ordinary product code.
A few old replay source bytes are unavailable as stated in the index; their
hashes are not claimed to match the final retained CLI.
