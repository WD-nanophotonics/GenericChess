## Controlled pairwise comparisons

The comparisons are joined by sample and seat assignment, so each row uses the
same A/B tape values in both cells:

- `ORTHO4_CURRENT` versus `FULL8_CURRENT`: V4-3 A/B stayed ongoing, B/A
  stayed stalemate (29 versus 23 plies); V5-3 A/B changed from ongoing to
  stalemate (32 to 10), and B/A stayed ongoing.
- `ORTHO4_HOME` versus `ORTHO4_CURRENT`: V4-3 A/B stayed ongoing, B/A changed
  from HOME ongoing to CURRENT stalemate (32 to 29); both V5-3 pairs stayed
  ongoing.
- `FULL8_HOME` versus `FULL8_CURRENT`: V4-3 A/B stayed ongoing, B/A changed
  from HOME ongoing to CURRENT stalemate (32 to 23); V5-3 A/B changed from
  HOME ongoing to CURRENT stalemate (32 to 10), and B/A stayed ongoing.

No cell produced a decisive game or checkmate. The controlled result does not
support `FULL8_ESCAPE_CAPACITY_TOO_HIGH`: FULL8 did not have more ongoing
games than ORTHO4 without a stalemate tradeoff in both samples. The controlled
HOME/CURRENT differences are one-directional in the changed pairs for both
Anchor profiles, so `ANCHOR_PLACEMENT_INTERACTION_OBSERVED` remains a bounded
descriptive route. `MATE_CAPACITY_REMAINS_LIMITING` remains supported as an
independent descriptive route because all four cells have zero decisive games.
