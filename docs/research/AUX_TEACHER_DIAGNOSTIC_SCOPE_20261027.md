`LearningDiagnosticCorpus` stores the full `action_history` from the default compiled initial state. Both `nonterminal_positions` and `_search_position` replay every action through `GameSession.submit`. Therefore this is NOT a board-only corpus, and the source does not justify alleging generic history loss. The corpus's `position_key` is an integrity check, not the whole replay state. `validate` additionally checks ruleset fingerprint, replayed position key, side and ply. The schema is nevertheless narrower than arbitrary modern GameRecords: it represents actions from the compiled default initial state, not an arbitrary custom initial-state record/declaration sequence. ## A concrete result-admission defect

`teacher_benchmark` originally compared `str(result.action)` without completion/fallback admission. Two `action=None` results therefore counted as perfect agreement, and fallback-only identical legal actions also counted as completed deeper-teacher agreement. A legitimate empty nonterminal corpus divided by zero. Controlled `_search_position` stubs reproduce these actual function behaviors without constructing a Player, Native engine or game. The original10 new tests failed: several failures were new coverage assertions, not10 independent bugs; the before XML preserves the exact failures.

Narrow repair: compare typed actions only when action is present, completed_depth>0 and used_fallback=False. Retained completed iterations under node/time limits remain eligible; equal requested max depth is not required. Return `None` for a full-panel agreement when ANY required comparison is unavailable, preserving the original denominator with positions/valid_pairs/matching_pairs in comparison_coverage. No invalid pair is relabelled as agreement/disagreement or silently filtered to inflate a rate. Empty panels likewise yield unknown, not0/perfect. Invalid max_positions values and missing checkpoints fail before search. Downstream teacher/next-phase and learning-retest verdicts handle unknowns explicitly instead of comparing None numerically. Valid complete panels retain their prior action-agreement values.

This is a result statistic correction, not a training rule, new oracle requirement or an instruction to rerun old studies. Agreement with Gen0 at a larger node cap is a reference-policy diagnostic; deeper self-agreement is consistency, not WDL correctness or proof of superiority. Current source cannot establish that historic teacher comparisons actually contained missing/fallback results; no historical gain is retracted or strengthened.

### Own finite-terminal-payoff qualification

Do not mechanically apply a horizon-squared cumulative-cost slogan to terminal-only WDL. For ONE fixed root law, complete rule-terminated games, the same fixed opponent, deterministic teacher policy and a frozen student policy, pad terminals with a shared absorbing no-op to at mostT own decisions. Couple the two plays to use identical opponent randomness while their histories agree. Let epsilon_t be the student's probability of disagreeing with the teacher's action at a time-t state under the TEACHER occupancy law. The first divergence probability is at most sum_t epsilon_t: every first-divergence prefix has no greater mass than its corresponding teacher prefix. If there is no divergence the terminal utility is identical. Since player-0 WDL lies in[-1,1],

abs(E[Z_student]-E[Z_teacher]) <= 2*min(1,sum_t epsilon_t).

The same first-divergence union argument can use STUDENT occupancy instead; neither occupancy is furnished by the arbitrary diagnostic corpus. With a stochastic teacher, the conditional total-variation discrepancy under an appropriate action coupling replaces deterministic disagreement; independently sampled action mismatch is not itself that TV distance. This is an own elementary coupling result, not a newly verified paper theorem or an empirical quality estimate. It gives closeness to the specified teacher, never superiority to the teacher, minimax truth or cross-rule transfer. It assumes complete actual scoring outcomes, matched roots/opponent and the relevant full history/policy memory; timed incomplete queries and resource-censored games do not acquire WDL targets through this argument. No epsilon or resulting bound is numerically certified for existing runs.

The paper's cumulative task-cost bound addresses a different target and can remain horizon-squared. Terminal WDL has fixed range, so the damage after a first divergence is bounded by2 for this particular task. This distinction prevents both an exaggerated intrinsic impossibility claim and an unsupported claim that arbitrary high corpus agreement proves learning/play gains.
