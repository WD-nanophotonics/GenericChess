# Frozen inventory support/transfer bound

The additive-capability identity requires compatible actor statistics under a
common joint law. Before scoring more types, audit one exact invariant of the
current single-focal sampling law versus an actual-inventory reference law.
No claim that either law is uniquely selected by rules or strategically valid.

Use compiled initial Chess/Shogi owner/base-type inventories only. In the current
sampler, the physical focal placeholder is one owner0 P; substituting base type
t yields count vector I_mu(t)=I_initial-e_(0,P)+e_(0,t). Compare any NONEMPTY
reference distribution that retains I_initial and places an actual existing
owner0 token of type t at the focal source. Common quiet/Pawn conditioning,
placement weights or reachability restrictions cannot change either count vector.

For every unpromoted ordinary query type (five Chess/seven Shogi), record both
vectors. Prediction before execution: P vectors coincide; every other type's
vectors differ by L1 distance2. Thus their supports in full Position space are
disjoint whenever both laws exist. Choosing the event 'inventory=I_mu' proves
total variation1, under convention TV=sup_A|mu(A)-nu(A)|. The bounded-task
transfer bound |E_mu X-E_nu X|<=TV is then only the trivial <=1 bound.

This does NOT show their task means differ, reject an approximate prior, prove
reference support nonempty, or demand changing the focal replacement law.
Equal inventories for P also do NOT prove identical measures or TV0. A shared
reference background can legitimately define a conditional prototype score;
its transfer to actual inventory or another game needs a separate argument.
Low-dimensional projections might admit tighter transfer bounds, but cannot
silently discard background/terminal effects already shown to matter.

Hash the protocol and sampler source; no transition enumeration, placement
repair, values, human references, resampling, stronger worker or new framework.
