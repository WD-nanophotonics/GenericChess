# S3 transaction closure and actual caller intent

The decision is to defer broad S3 setup and test a minimal **explicit full-frontier
caller interface** next. The production engine remains at the tested 2d1bed
implementation. This segment closes129 actual public searches and one bounded
caller observation within those129; private prototype correctness, caller cost
and completed-depth delivery are separate evidence.

## Question and conditional semantics

The preceding endpoint fallback removed expensive attack scheduling on large
rules. Remaining q4 cost included complete legal-frontier/S3 construction.
Unchanged checks outside enemy geometry suggested reuse, but the valid remote
capture-guard counterexample already refuted geometry-only generalization.

The tested conditional premise requires all capture patterns to have no state,
slot or square-zone guards, and only the five existing prefix occupancy/owner
path predicates. Construct influence from **all** actual enemy actors' complete
source/path/target routes to the current own anchor, including blocked rays.
Perform the original complete transition first. Read its actual board writes
through WorkingPosition.set_piece, including promotions and compound effects.
Reuse parent own-anchor safety only when final changed Pieces do not touch that
influence, change/create a surviving enemy, remove/change an own anchor or create
a new own anchor. Otherwise run the original child query.

This only substitutes the own_anchor_safe branch. Every other S3 invariant,
full S4, actual child, hand/aux lifecycle, triggers and relevant history remain.
Rules outside the condition use the complete original path; their semantics are
part of the target. No game ID, position patch or persistent position/score/
history cache is admitted. The finite controls qualify this premise, not all
possible future extensions of the DSL.

## Actual bottleneck and next interface

The scoped1962 profile performs62,945 S3 trials and skips62,230 child check
queries. Original in_check calls67,038 become9,116, but preparing4,308 contexts
costs2.10–2.12 profiled seconds. Preprocessing replaces much of the saved work.
Write tracking's own method time is much smaller; another tiny tracking/helper
patch is not the selected question.

The independent consumption observer identifies the existing
SemanticEngine.has_legal_action/terminal push callers as first-only existence
checks. SearchPathRuntime.legal_actions materializes all semantic bindings,
including complete public actions and binding identity. Its cache hits do not
reconstruct frontiers. The real totals are **4093 first-only,215 exhausted**;
a checkpoint initially guessed4100/208 from top groups and was immediately
corrected without changing the original data or hiding the incorrect checkpoint.

The next smallest engineering trial is explicit full-frontier intent at this
existing Core caller, with local context passed through S3 rather than suspended
engine state or production frame inspection. Preserve original existence paths,
entry validation, optional-observation decline, every other invariant, required
errors, child identity and cooperative cancellation. Test fresh equal-resource
controls before deciding adoption. Broad setup, new engines, persistent caches,
UI/default changes and per-seed rules are not selected.
