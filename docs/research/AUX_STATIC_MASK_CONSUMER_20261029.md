## What the preserved evaluator actually computes

In the strict admitted all-Leap footprint, each attack set is a finite union.
Replacing it by integer OR preserves membership, and bit_count preserves its
cardinality. Friendly-occupied targets and pinned pieces still count; using
legal moves as the expected set would be wrong. Short anchor escape uses the
same precomputed subset, removes ALL occupied and opponent-attacked squares,
and selects the first anchor in board order. In a concrete two-anchor static
control, selecting the other anchor changes the raw value by75; the mask keeps
the first-anchor reference result. Synthetic multi-anchor/large-hand inputs are
static contract controls, not legal-game or strength samples.

Board values use current type, hands use base-type counts, and the final sign
uses side to move. An empty promotion-zone map makes the reference bonus zero
in this fixed instance. Cached geometry/steps and current config/profile are
assumed fixed for the instance; no unsupported mutation contract is invented.
Fingerprint failure behavior depends on active dynamic terms in both paths.
Raw values are compared before the search's separate static clamp.

The maintained AUX learner supplies its own Material evaluator override and
configuredQ0. This mask constructor requires the exact default Evaluator type
and rejects that override. Its pseudo-attack optimization is not called by the
maintained material adapter. Infrastructure availability and actual learner
acceleration remain distinct; no learner speed measurement was made.

confidence intervals, new acceptance gates or repairs of the zero-group gate.
No additional clock experiment follows this calculation.

## A behaviorally inert declaration still changes the baseline profile

One separate counterfactual appends ordinary UNUSED with Leap(97,99), zero
initial board/hand inventory and false drop masks to the source family's second
layout `ce7-f0-h1`. All old active IR patterns match under an explicit pattern-ID
bijection, all old geometry/tables remain identical, and the mask admits both.
There are no promotions, creation/transform effects, triggers, auxiliary state
or declarations; active board effects only move an existing actor or remove an
enemy. Therefore UNUSED inventory remains zero by induction on every legal
history. Old board/hands, actor and clock settings are preserved. Repetition
histories are related by fingerprint/position relabelling, not erased or used
as equal TT identities. This is a narrow bisimulation argument for these two
fully specified games, not a general arbitrary-semantic reachability solver.

Current generic-v5 semantic profiles conservatively normalize over all declared
types; legacy profiles close reachable types. All old raw capability scores
stay exactly unchanged, but adding raw0 to the semantic median changes it from
6.0973577017 to4.3781601778. The resulting tables are:

| C |436|607|436/436|

The source root has30 legal actions under the bijection. The first layout was
initially tried but had no ongoing one-ply raw-value witness; it was not a
failed performance slot or replaced statistical sample. In the second layout,
20 literal child comparisons locate the first nonterminal raw-value witness:
C from(3,2) to(3,4). Original/reference/mask score is-444; augmented/reference/mask
is-615. Material in seat0 units is436 versus607 and the dynamic contribution
is8 in both, before final actor1 sign. This identifies median scaling/rounding
and fixed dynamic-weight balance, not changed movement power. No Player was
run, no root choice or loss was measured, and no new minimax label was produced.

The initial consumer wrongly assumed compiler pattern IDs stayed identical.
Appending UNUSED renumbers12 old active patterns; a concrete old action can
be illegal until transported by the bijection. The corrected witness retains
this mapping and both full records. Fingerprints remain distinct, and no TT or
history label is reused merely because positions look alike.

A further explicitly specified Core control uses the reversible C c2-e2 /
C e6-c6 / C e2-c2 / C c6-e6 cycle. Both rules preserve the complete repetition
count map under a four-key bijection at every prefix. Board returns at plies4
and8 remain ongoing; the actual source fourfold rule draws at ply12. The
initial control assumed threefold and was corrected to the read source value,
without changing either rule. Search-state identity at ply4 differs from the
initial identity despite the identical board. These are two finite paired
12-ply contract traces, not engine matches, strength observations or minimax
DRAW labels. The explicit records and all count/history prefixes are retained
in history-transport.json.gz.

This is a baseline representation boundary, not a mask optimization mismatch.
Conservative all-type normalization is justified for unknown semantic creation
paths, but this strict subset permits stronger analysis. A future narrow
reachability-aware normalization could be evaluated under a new versioned
profile; changing current defaults, historical tables or claimed outcomes is
not part of this result. Inactive stock/type features are not automatically
assigned a true price of zero. Existing material-learner unitA and actual model
receipts remain a separate policy, not repaired by this static counterfactual.
