## Actual consumer and semantic boundary

Native transient legality really performs per-candidate S3 child/effect trials;
20 root audits measured candidate_count == s3_trial_count == attack_check_calls.
The existing Native attack membership index already exists. This work reuses it;
it does not claim to invent an incoming attack index or accelerate a Python
consumer that Native bypasses.

For admitted nonzero unblocked Leaps with only quiet-move/removal-capture effects,
enemy geometric attacks are independent of other occupancy. A nonanchor move can
resolve its own anchor's check only by capturing the sole checker. An anchor move
can test its destination against the pre-move enemy union: a captured piece cannot
attack its own square, and removing it does not uncover another Leaper. Royal
captures remain forbidden. Multiple checkers, perspective and OR union matter.

The isolated C entry guards actual executable IR/payload and current position:
3x3/H6/repeat2/3types, one anchor type and one anchor per owner, no extra active
path/state/slot/post guards or effects, no active promotion/drop/aux, ordinary
pieces with base==current, and ply<6. Canonical empty drop templates are inert,
not executable drop admission. Core still owns history, repetition, terminal
precedence, clocks and exact TT keys. No legality set/history/value is cached.

Complete syntax reuse stores only an immutable(public,SemanticAction,binding)
pair under(actual side,entire packed64 action) within a fixed rule/provider.
Every call first performs actual strict C position admission and legal generation.
Misses use the unchanged exact decoder/binding builder; hits reuse immutable
pattern/geometry/actor/source/target/promotion/path context. The real Core path
is retained, not assumed to be a singleton. Cache capacity2048 clears boundedly.
