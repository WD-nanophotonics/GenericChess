# Declared resource-marginal hypothesis before new labels

2026-10-05. Prospective approximate construction, no new game sample or
coefficients. Start from the scoped pin/deprivation task evidence, not a
renamed failed net-token or immediate-safe actor-count predictor.

For a complete public state/template z with ordinary physical own resources N,
fixed anchors/opponent/target law, define F_z(S) for each subset S of N as the
two-own-turn controlled designated-target/custody task. Missing resources are
explicit hypothetical absence, not capture into hidden hands. Preserve actual
legal choices/terminal/history in each independently declared coalition root.
The event must be the SAME for every S; if a designated source is absent,
completion is0 rather than silently changing which resource earns credit.
Unsupported coalition root/endpoint keeps[0,1], never omitted/renormalized.

Define a coalition-allocation hypothesis:
phi_i(z)=sum_{S subset N\{i}} |S|!(n-|S|-1)!/n! *
                 (F_z(S union{i})-F_z(S)).
For a frozen context law mu, a proposed mode prototype is the mean allocation
per physical own resource in that mode, integrating PUBLIC hidden-identity
expectations before choices/allocations. Source-role and supporting-role laws
must both be specified. No post-observation success filtering or type-specific
favorable target selection. Native/base/current/held roles remain distinct.
Common gauge is task units, not normalization by a possibly zero Pawn score.

This is a complete symbolic operator but NOT a frozen empirical candidate:
the finite common template/context law is still undefined. The rule-only law
must enumerate its support, exact masses, empty/invalid/unknown cases, targets,
resource/source-role sampling, fresh history, mode origins, endpoints and cost
caps before an estimate or any fresh independent use labels. No point vector
may be built from the exposed one-template pin table. That table is development
evidence of complementarity, not construction/validation separation.

Independent motivation: allocate a resource's marginal influence across
supporting coalitions instead of attributing all completion to its actor tag.
Changed premise versus old routes is explicit counterfactual JOINT-resource
influence and role attribution, not uniform-action service or inventory-count
regression. The assumed uniform ordering of resources is a modeling convention;
rules do not uniquely choose it, a target demand, or a background distribution.

Primary precedent: [Hart's author-hosted cooperative theory notes](https://math.huji.ac.il/hart/papers/value-lk.pdf),
pp44-45, give expected marginal contributions under random resource order and
efficiency for a specified transferable-utility coalition game. Their additivity
is across utility games, NOT additivity in inventory of one chess position.
We borrow the finite allocation formula; it proves neither Chess utility nor
static type transport. [Owen1972](https://pubsonline.informs.org/doi/abs/10.1287/mnsc.18.5.64)
describes a multilinear extension as a computation aid; its abstract does not
establish a cheap full legal-game coalition evaluator. Original Shapley RAND
PDF is scanned; no additional theorem is claimed from its unread text.

Smallest new falsifiers before a coefficient batch: sound partial-coalition
intervals; source-role bias under an explicitly fixed target event; replica
resource saturation; a coalition's added physical piece changing opponent
options rather than merely adding optional own actions; root/deletion history
compatibility; and cost under the existing128-transition/5000-choice limits.
Failure narrows this allocation or context law, not all approximate priors.
Full exact mode-independent WDL/additivity is not a prerequisite to explore.
