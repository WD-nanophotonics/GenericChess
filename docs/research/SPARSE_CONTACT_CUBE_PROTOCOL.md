# Prospective shared sparse-occupancy contact primitive

Purpose: extend the cheap shared compiled-geometry approach to intrinsic path
counts, exact-empty guards and zones, using existing qualified occupancy cubes.
This is a semantic primitive, not a newly selected formula or Xiangqi price.
No human holdout, old deployment labels, complete Xiangqi coefficient population
or new independent goal values are read. The diagnostic builder remains
movement-only, not full historical Xiangqi certification.

Input is compiled IR plus explicit ordinary physical profiles, not game/type
names inside the algorithm. Uniform ordered distinct(source,target,one passive
own blocker) remains the declared virtual world shape. Retain dead/out-of-zone
source worlds as zero, not renormalized legal placements. Only source acts,
target ordinary/passive, each actual quiet move changes source position/current
mode, origin persists; no royals, opponents, stock/history or drops in this
primitive. No action/value or generic-game admission silently fills a gap.

Reuse event_cubes_for_candidate for the declared intrinsic grammar. Reject the
WHOLE supplied profile closure if any board pattern has unsupported history,
postconditions, auxiliary mutation, non-source move or off-target removal.
Compiled simple promotion variants retain profiles; duplicate physical events
union their cube masks. Same geometry key must have identical compiled paths;
canonical geometry-source candidates cached/shared rather than repeated by type.

For a fixed(s,d) cube, source occupancy=own and designated target=enemy; other
squares are empty except b=own. Project a conjunction exactly into allowed-b
bitsets, union alternative cubes. A quiet first move to u requires u distinct
from d,b, empty-target cubes evaluated with ORIGINAL enemy d, source s; then
source s vacates, second capture cubes use source u and the same d,b. Promotion
current/origin profiles persist. No independence approximation or screen mask
treated as path-clear. This yields exact first/second contact masks for the
accepted intrinsic grammar; unresolved deeper paths remain unknown.

Before measuring anything, declare selected diagnostic controls: Cannon
same-file one screen versus off-file screen, Cannon two-event corner route;
Horse blocked/unblocked leg; Elephant blocked/unblocked eye and cross-river;
Advisor palace/outside; Soldier lateral before/after river. Use owner0 and full
180-degree owner reflection. No coefficient scan. Save complete semantic root
action lists for each control and compare direct-contact membership, not full
game WDL. A single named Cannon quiet/capture continuation is additionally
executed position-level with explicit own-turn reset, not alternating history.
Missing royals are deliberate; source guard semantics only.

One frozen producer,128 patterns/128 physical events/128 choices per root,
5000 canonical geometry candidates and5000 explicitly enumerated semantic
actions,15sec total cooperative cap. No rerun/cap enlargement on failure.
Replay tests independently verify bitset projection and leg/eye/screen/zone
controls, strict unsupported-grammar rejection and immutable input hashes.
