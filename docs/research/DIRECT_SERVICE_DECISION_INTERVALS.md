# Finite-service uncertainty targeted at material decisions

2026-10-04. Prospective analytic use contract, not an admitted vector, new roots
or independent outcome evidence. Changed question: must every component be
estimated to the same decimal precision before any material decision is useful?

## Deterministic partial integration for a declared finite law

Freeze representative roots x_i with rational weights h_i summing to1 BEFORE
outcome/use measurements. This defines an approximate finite-context constructor,
not an unbiased estimate of a natural-play population. Complete root choices
give g0_i and A_i. The exact target is

    v = sum_i h_i [g0_i + sum_a E_opponent W_ia / A_i].

A certified bound b_ia yields [0,b_ia] for any unexamined own-action continuation.
If its complete opponent set has B_ia choices, each branch has weight
h_i/(A_i*B_ia). Exact qualified next-own integration replaces that branch's
[0,b_ia] with [r,r]. Endpoints become [0,0] only after authoritative qualification.
Until opponent enumeration is complete, retain the WHOLE own subtree bound
h_i*[0,b_ia]/A_i; a visited prefix is not its renormalized opponent population.
This tree accounting gives an enclosing coefficient interval at every stopping
point, with no stochastic confidence or optional-stopping problem. Timer/cap
failure leaves the remaining interval, never zero or a smaller target law.
If root enumeration/g0 itself is incomplete, that root also remains unresolved;
the exact root reward is not inferred from a prefix. Trace/semantic failures
cannot be certified with a numerical interval alone.

For held tags only D drop subtrees have b=1/n; the initial full future gap is
D/(A*n). For board tags a conservative b=1 is valid, but a bound must not be
invented from one observed zero path. Root and branch state/history stay intact.
No mode refresh, stock repair or fourth-ply rollout is part of this target.

## Relative precision sufficient for a particular material choice

Let each raw H2 component have interval v_t in[l_t,u_t] subset[0,2]. For two
ongoing children, let d_t be their signed inventory-count difference multiplied
by +1 for owner0 or -1 for owner1. The raw oriented score margin has enclosure

    L = sum_{d_t>=0} d_t*l_t + sum_{d_t<0} d_t*u_t
    U = sum_{d_t>=0} d_t*u_t + sum_{d_t<0} d_t*l_t.

Thus uniform per-component precision is unnecessary for THIS comparison: modes
with d_t=0 do not matter, and the uncertainty width is sum_t |d_t|*(u_t-l_t).
This is a decision-stability certificate, not a certificate of good goal utility.
Exact box extrema may be conservative when coefficients are correlated; preserve
such correlation if qualified, never assume independent uncertainty to narrow it.

All raw H2 values share bound2. A fixed normalization v_t/2 and the existing
ordinary-token bound N give nonterminal E=sum_t v_t*Phi_t/[2*(N+1)] strictly
inside(-1,1). This is a COMMON positive scale, hence preserves nonterminal
ranking relative to normalization by any nonzero maximum component. It avoids
dividing interval coordinates by a varying, correlated estimated maximum.
It does not rescale held/board components individually. Authoritative +/-1
terminal results still dominate and qualified draws use0; unknown claims remain
incomplete. This prospective interval operator is not silently substituted into
the existing frozen point-score primitive or its historical reports.

To certify one complete-table selected choice a under every vector in the box,
compare against EVERY legal choice b, not just one mixed-sign witness. Require
L(a,b)>=0 when a wins the canonical tie against b; require L(a,b)>0 otherwise.
The strict boundary matters because a lexicographically earlier competitor can
win a zero-margin completion. Terminal rows use their authoritative fixed scores
and are not converted into inventory intervals. Missing material modes remain
unsupported even if a particular pair's difference cancels them.

## Useful next experiment, without premature labels or new budgets

For a separately frozen finite-root candidate law, retain service coefficient
intervals and complete material-choice tables. If all vector completions select
the same child, expensive additional coefficient precision does not change that
root's deployment; freeze the selection, then compare its independently observed
goal interval against unit/zero as already designed. If selection is uncertain,
prioritize a qualified unresolved construction branch contributing to a relevant
|d_t|*(u_t-l_t), within the PREDECLARED total caps. Exact deterministic interval
refinement permits that computational ordering without changing the target.
Do not choose a new population, horizon or coefficients using goal labels.

This is a cost/use premise, not evidence that a tiny finite law is well motivated,
that all types have positive service, or that it outperforms any baseline. A
complete finite-context law, full semantic scope and compatible independent
goal certificates remain separate gates. Partial intervals can honestly show
inconclusiveness without rerunning until a favourable selection appears.
