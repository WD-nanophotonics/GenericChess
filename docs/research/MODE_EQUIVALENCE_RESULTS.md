## Deployment implication

Do not require an origin-mixture estimator universally. A qualified equivalence
class can instead constrain coefficients equal. Here the matched Chess Q
controls support equivalence only for this synthetic rights-free short-history
scope; broader semantic proof remains needed. Native/promoted Queens' different
full-resource reference means3/68 versus1/12 compare different environments,
not identical Queens' intrinsic ability. Arbitrarily assigning them separate
static scores would encode a context proxy unless independently justified.

Keep Shogi board current types and held base types separate. Equal movement
atoms are insufficient for interchangeable future resources, and erasing its
promotion to Gold would violate base/custody semantics. Existing current-type
material feature interface is therefore retained, not extended merely because
the research bookkeeping uses refined origins. No candidate admitted yet.

Next useful directions: qualify an encoding-invariant declared policy and
formalize how an action-competition statistic could become a static prior;
derive wider Chess same-current equivalence where history/rights permit;
or implement the pure conditional DTM/horizon bridge independently of missing
external table files. Avoid more uninformative lifetime coefficient batches.
