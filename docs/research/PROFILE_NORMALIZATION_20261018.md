## Question and consumer

The served default profile normalizes each rule's raw movement-capability
scores by the rule's median ordinary piece, rounds to integers and clips to
`[1, MAX_STATIC_EVAL]`. Cross-game and rule-only price work wants to compare
piece values as ratios. The question: in a deterministic sample of generated
rules, do normalization, rounding and clipping preserve the raw ordering and
ratios, or do they create ties, inversions or clipping that would make the
normalized integers unusable as ratio evidence?

The consumer is rule-only generic pricing: whether a published normalized
value can stand in for a cross-rule ratio, or whether raw capability scores
must accompany it. This is a static-profile measurement with zero search; it
is not a strength, utility or game-outcome study.

## Method

Forty deterministic rules, seeds 291001-291040, `board_size=4`,
`setup_preset=classic_like`, generated by `generate_game`. For each rule the
served profile is built with `EvaluationConfig(hand_weight=0.9)`. All
non-anchor piece types are inspected (120 types total, three per rule in this
family). No position is searched.

Pre-written endpoints in `plan.json` (SHA-256 `EEADD8CA...`):

- ceiling clip: normalized board value equal to `MAX_STATIC_EVAL`;
- floor clip: normalized board value equal to 1;
- ordering inversion: one type has a strictly larger raw score but a strictly
  smaller normalized value than another;
- tie group: two distinct raw scores map to the same normalized value; a
  **material tie** has a within-group raw ratio of at least 1.10;
- ratio distortion: for type pairs whose raw ratio is at least 1.05,
  `|normalized_ratio / raw_ratio - 1|`;
- cross-rule raw equality for repeated movement signatures;
- hand/board rounding deviation from the configured 0.9;
- promotion-gain consistency against `max(target board value) - source`.

The decision rule was written before the run: any inversion or ceiling clip
records `defect_detected`; otherwise at least 10% of rules with a material tie
records `coarse_normalization_supported`; otherwise
`ratio_rounding_bounded`.

## Results

| endpoint | observed |
|---|---|
| rules / ordinary types | 40 / 120 |
| rules with an ordering inversion | 0 (0 inversions) |
| rules with a ceiling clip | 0 (0 types) |
| rules with a floor value of 1 | 0 (0 types; weakest normalized value 101) |
| rules with any tie group | 0 (0 groups) |
| rules with a material tie | 0 |
| pairs with raw ratio >= 1.05 | 113 |
| maximum ratio distortion | 0.5049% |
| median ratio distortion | 0.0314% |
| repeated movement signatures | 18 |
| raw-score mismatches for equal signatures | 0 |
| promotion-gain checks / inconsistent | 62 / 0 |
| hand/board rounding deviation, max | 0.002913 |
| hand/board rounding deviation, median | 0.000125 |
| stored decision | `ratio_rounding_bounded` |

The largest observed ratio distortion is 0.5049% (seed 291031, pair `P`/`X`).
It is not a threshold artifact: that pair has a raw ratio of 10.01, and the
weak piece normalizes to only 103 while its partner reaches 1026. One integer
step at 103 is about 0.97% of that value, so the whole distortion is explained
by the weaker member's rounding granularity. Quantization error on a ratio
therefore scales roughly as `0.5/min(normalized values)`, which is the useful
statement: absolute ratios with a very low-valued member carry up to ~0.5%
relative error even though the median distortion is 0.03%.

No two distinct raw scores collapsed to the same integer, so the normalized
values retain the raw ordering at the observed resolution. No value reached
either clip, but the floor endpoint was never exercised: the weakest ordinary
piece in the sample normalized to 101, so a value of 1 was not attainable in
this family and that column is vacuous rather than reassuring. Equal movement
signatures produced exactly equal raw scores across rules, as the capability
construction implies.

## What the results do and do not show

- In this 40-rule `classic_like` 4x4 sample, normalized board values preserve
  raw ordering and ratios to within 0.51%; no clipping or tie compression was
  observed.
- Ratio error is governed by the smaller member's integer granularity, not by
  the pair's raw spread. A 10x ratio here carried the largest error (0.50%)
  because its weak member rounded to 103; two 1.05-strength neighbours would
  round far more accurately in absolute terms.
- This supports using normalized values as descriptive ratio evidence **in
  this sampled regime**. It does not prove ratio preservation for other board
  sizes, movement families, extreme capability ranges or larger type sets,
  where clipping or integer ties are more plausible.
- The three ordinary types per rule give only three pairwise comparisons per
  rule; a larger type set would create more opportunities for rounding ties.
- Promotion gains and hand values are internally consistent with the board
  table in this sample, but consistency is not evidence that the table's
  weights are strategically correct.
- No strength, playing-quality, utility or human-price claim is made.
