# Immediate terminal goals and explicit semantic backends

The Native semantic engine now offers an explicit physical-win decision goal.
Default finite analysis, UI routing and evaluator formulas are unchanged. An
explicit backend compilation entry also replaces source-exec/module-switch
workarounds for known versioned backends. The optional wide image stays a

Science is OPEN. No stronger-play, universal price or whole-domain claim.

## Delivered API and truthful completion

`SemanticSearchEngine.search(..., stop_on_immediate_win=True)` and the one-shot
`semantic_iterative_search` opt into a verified root-child decision. False is
the default and retains old-kernel calling compatibility. True requires the
creating backend to advertise the feature; it never silently downgrades.

The proof is the actual terminal result of a fully checked Native child under
complete rules/history, with winner equal to the root player. It is not a
mate-like evaluator score, a declaration, a draw, or a multi-step heuristic.
The flag is committed only after binding the completed child to its root action.
The incomplete root is not entered as a completed finite root TT result.

A prefix win returns `immediate_win=True`, a one-action PV, and
`result_source="verified_root_child"`. `completed_depth` stays0 and completed
ordinary/hard-q policy staysNone: the whole D1 iteration did not finish. A
coincident node/time/cancel stop retains its real termination reason. Existing
finite iterations, fallback and terminal-position sources are distinguished.
The two new result fields are appended, preserving older positional field order.
Full Native checked PV replay and dynamic metadata remain in the product caller.

Real regression: at12nodes the fixture has no proof and uses fallback; at13 it
retains a genuine terminal win while reporting node_budget/D0; at14 it reports
the same proof with root_immediate_win/D0. Both root-window modes, cold/warm TT,
root-ply offsets, actual played perpetual-check history, neutral declarations,
ordinary declarations, draw/max-ply, pre-cancel and raw-parser recovery are
covered. No change to AUX's generic prover, verifier or StrategyCursor.
