# Board versus charged masked hand under the declared common demand

New aggregate-law certificate, not a physical game premium. Both comparison
statistics use the SAME (d,b) parent law, with passive blocker tag uniformly
over7 native types. The unrestricted board source is uniform over79 remaining
squares. The held prototype selects a subset A(d,b,type) of those squares and
pays one extra own preparation action. Keep all parent/world masses.

For fixed gamma, nonnegative route reward implies

    H(gamma)<=a*gamma*B(gamma).

Here a bounds79/|A| after averaging blocker tags. Use a=79/70 for L,79/61 for N,
1 for unrestricted S/G/B/R. For P, six non-P blocker tags have |A|>=70 and
the native-P nifu tag has |A|>=63, so

    a_P=(6/7)*(79/70)+(1/7)*(79/63)=2528/2205.

Board route values do not depend on passive blocker's type, so this tag average
is legitimate; do NOT average denominators of different occupied locations.
Each bound applies pointwise in(d,b), before averaging. Dropping masked-out
nonnegative terms gives an upper on H, not a same-placement equality.

Under fixed gamma1/2, B-H>=(1-a/2)B>0 for all seven modes. Under the shared
mixture the bound is E[(1-a*gamma)B(gamma)], NOT (1-a*Egamma)E[B]. For a finite
distance t its coefficient is f(t)=m(t)-a*m(t+1). Use frozen exact first/second
and available third masses; preserve known zero support and every remaining
reachable world. For unresolved reachable distances t in[cutoff,D], use the
MINIMUM signed f(t) over that finite interval, even if negative. This avoids
an invalid positive monotonicity assumption or midpoint distance.
