## Locate overhead before changing an interface

The previous 32 signed D2 calls had median nonkernel search-call fractions of
75.0%/81.7% for False/True. Ninety additional timed-wrapper calls use the same
fifteen full inputs, retained sessions/TT0 engines, D2/D6 and three repetitions.
Their scientific outputs match the existing qualified controls.

For D2, the measured median caller fractions are approximately 13.6% full-history
packing, 3.1% public-action decoding and 1.3% returned-leaf dynamic features.
These wrappers add cost, and their unassigned residual does not identify a
single cause by subtraction. In particular, this evidence does not justify
discarding complete history or returned features.

Source inspection finds twelve 1025-element diagnostic arrays projected through
Python integer-generator loops. The Native arrays and every public field are
kept. A separately frozen, randomized paired A/B uses actual baseline/candidate

repetitions on fifteen contexts. All fields, nodes, actions, PVs and parents
match, including all twelve full integer tuples. Timing fields are retained
but are not exact-equality targets.

The prewritten adoption rule requires at least 10% aggregate D2 call savings
and no more than 10% aggregate D6 regression:
