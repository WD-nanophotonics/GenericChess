# Policy-cost and quantity evidence

`packet.json.gz` contains60 exact UTF-8 technical originals/source entries as JSON
strings. `manifest.json` hashes compressed/decoded bytes and every original.
No capsule is executed or unpacked. The interpreter account path is normalized
only in the execution publication copy; its private original hash is retained.
The fixed OLD screen remains in `../leaper_forward_width_20261024/` at Git
b66566c3647918b4c2f40993869ff0c46fb75e9b; source/inputs/results are not rerun.

Run the maintained data-only reader into a NEW ignored output:

```
.venv/Scripts/python.exe -X utf8 -m scripts.leaper_cost_decomposition --packet docs/research/data/leaper_policy_cost_20261024/packet.json.gz --old-screen docs/research/data/leaper_forward_width_20261024/screen-evidence.json.gz --output .local_agent/NEW-policy-qualification.json
```

`summary.json` includes all registered cost associations and current quantity
results. `quantity-witnesses.json` exposes full selected Core two-action trees
and explicit synthetic/static configurations in plain JSON. `next-inputs.json`
and `next-cost-inputs.json` expose two SAME-RuleSet setups and four complete
initial/4ply cost contexts. These plain views are LF-normalized presentation
copies; byte-preserved original input hashes refer to packet documents.

`common-time-diagnostic.json` is a separate post-registration zero-query
same-input intersection calculation. It includes exact membership, source and
independent stdlib tied-rank/integer-covariance cross-check. It is not inside the
packet's Core replay result, not a new headline/fit, and selects on stopping.
`qualification.json` records the actual packet replay scope. Its next-prefix
count denotes8 unique prepared steps; repeated full-record replay is not
presented as independent evidence.

Capsule recovery is explicit: the earlier quantity source was reconstructed
from additive edits and exactly matched its original recorded SHA; the earlier
matched-query caller was recovered from the fixed Git/newline candidates and
exactly matched its recorded SHA. Executed/new metadata-fix sources differ and
remain separate. Shared Core is not an independent engine; static synthetic
positions do not prove opening admission/reachability, and legal PVs do not
prove all-defense WDL. No defaults, learner, sampler or AUX state are changed.
