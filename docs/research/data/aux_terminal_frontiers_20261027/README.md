# AUX terminal-frontier evidence

Fixed-source, exposed-history validation; no Player/game/training campaign.
Exact and one-sided facts are different. Unknown continuations remain unknown.
frontiers.json.gz is the final one-step pass; partial-bounds.json.gz is a
backward deduction on only those edges. verified-strategies.json.gz records
all77new finite AND/OR checks and a complete concrete witness. Other files
retain horizon/learning/denominator/multi-action controls. sources.json binds
every gzip and executed source. Originals of Slack/Pro reads remain ignored.

Reproduction uses the existing own Python environment and public source object
c695161cbc16fe5881773d4465ad00c1c5e1181e (fetch sandbox if absent), without merging
or executing archived producer code. Run scripts.inspect_pvs_terminal_frontiers,
then scripts.propagate_pvs_terminal_bounds, scripts.verify_terminal_frontier_proofs
and scripts.analyze_frontier_learning_limits with explicit --frontiers/--derived/
--output paths. Each module has --help. Store regenerated outputs privately.
No oldH6 solve or state/TT quotient is part of this pipeline.
