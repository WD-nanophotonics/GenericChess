# Literal technical evidence

These are project-only scientific publication copies. Sealed packet metadata
records original capture status,not a live publication or permission gate.
They exclude private Slack wrappers, account metadata and session ledgers.
No archived source is automatically executable and no archive is a default
activation or permission to repeat an expired experiment.

`inputs.json.gz` contains eight complete admitted pure-Leaper RuleSets and
post-material-removal root records, plus sixteen original finite-clock records.
These are exposed development inputs, not an independent holdout.

`source-evidence.json.gz` and `source-dependencies.json.gz` are literal UTF-8
maps. Each `members[original_relative_path]` includes `utf8`, byte count and the
SHA256 of the original bytes. Encoding `utf8` back to UTF-8 must recover that
hash, including original newlines. They retain the failed initial selector,
frozen plans, complete full-history input census, negative certificates,
skipped reasons, independent source acceptance and finite-clock controls.
The dependency supplement contains the exact old descriptors/certificates used
for reuse; it neither refills old missing slots nor creates new source queries.

The LMR bundle and final manifest were sealed after producer closure and
independent acceptance. The caveat/next bundle retains the failed one-child
diagnostic and the prospective baseline-only preselection. Literal raw Player returns stay separate from later
submission/PV metadata; missing and aborted slots are preserved explicitly.
Every archive is immutable once sealed. Manifest hashes refer to compressed
bytes; member hashes refer to the literal original uncompressed bytes.

For reproduction, inspect the manifest and pinned sources first. Recover
relative scientific data in an isolated matching checkout, verify every member
hash, and use the independent readers on the recovered frozen plan/evidence.
Do not overwrite an active `.local_agent` run, import another policy's TT,
execute source stored as data, or rerun an expired query to replace a failure.
The source reader uses the shared Core; it is an independent literal replay,
not a separately implemented game/WDL engine. LMR is a selective research
wrapper and its nominal depth/TT scores are not exact minimax certificates.
