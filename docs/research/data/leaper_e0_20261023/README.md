file byte hashes in `original_file_sha256`. Reencoding those values does NOT
recreate original whitespace/order/BOM bytes. Exact old source capsules are
hashed by UTF-8 bytes; current ordinary scripts may contain later analysis-only
repairs. Original registration/source remains evidence, not an approval bypass.

A NEW independent reproduction can materialize a run into a fresh output directory
with the existing `scripts.leaper_calibration_run --materialize-from-packet ...
--group e0 --output .local_agent/NEW`. That preparation makes0Player calls,
retains the original registration and binds new serialization bytes, preparation
time and provenance. To execute a NEW replication, use `scripts.leaper_e0 execute`
with its output; it makes NEW preflight calls, freezes predictions before NEW
fitness and enforces the registered cooperative cap. Existing completed/censored
runs are never resumed. The `small-interrupted` group is CLOSED cost failure,
not an executable resumption or recommendation to repeat1920slots.

`python -m scripts.leaper_e0 analyze --output NEW` and
`python -m scripts.leaper_e0_mechanisms --output NEW` analyze complete retained
price/depth runs; `python -m scripts.leaper_e0_checks --output NEW` qualifies
literal histories/PVs and D0winning-child exceptions, without new Player calls.
The same read-only packet verifier also accepts `e1-transfer.json.gz`.

These commands do not implement AUX's solver, learn player prices or change
production defaults. The handoff and source URLs are pinned in the report.
