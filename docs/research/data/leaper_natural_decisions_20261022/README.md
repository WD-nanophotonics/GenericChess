The verifier uses shared Core and the existing sibling
`leaper_primary_AB_truth_20261022/verify.py` proof helper. It needs neither
private caches nor network access. It checks all receipt arithmetic, replays
20 actual all-defense certificates/9,168 Core nodes, rejects two corrupted
proofs, reconstructs the price witness's complete D2/D4 argmax sets, performs
six independent public-search checks, and closes the safe capture's
2,298-state/9,510-edge subgame.
It also repeats ten canonical-interface learner checks/103 nodes. These checks
do not rerun PRIMARY's forward screen or establish new strength/speed gains.

The default verifier does **not** reconstruct every full graph or every
history-WDL label in the census. Those remain local complete-graph results
under the declared restricted history/clock argument. Their labels are used
as given when recomputing the full compact-query arithmetic. The standalone
price witness has its own losing-child win proof and safe-capture draw proof.
