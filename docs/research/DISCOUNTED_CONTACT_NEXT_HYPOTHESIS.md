## What differs from historical V2H, and what is already spent

Read source definitions only: ADR-133 computes uniform current-type support
from a union of positive-support topology edges, then averages local U+C.
It introduces no distance/depth/drop-frequency weight. The V2F helper already
has BFS distance summaries and transition-depth summaries; its own definition
explicitly warns that graph hops are not real plies or survival/deployment
probabilities. Thus simply adding a discount to OLD graph-hop numbers is not
a new faithful action-time constructor or an independently validated candidate.
Old Chess/Shogi V2H development results remain spent; current freeze/source
drift and rectangular Xiangqi applicability remain as previously documented.
No old candidate is rerun, rebased or selected on human reference values.

## Changed premise worth examining before computation

For every candidate contact path, require one COMPATIBLE evolving source mode,
physical target and background occupancy/guard trajectory, instead of composing
separate positive-support edge witnesses. Ordinary moves, captures, promotion
and held-native deployment must use their actual respective semantics. Native
origin/history dependence cannot disappear from the graph node label. Specify
whether this is a relaxed single-agent task, a real alternating action task or
a projected capability task; these have different tau. Neither stationary
opponents nor reset side-to-move are official game turns. Declare any relaxation
BEFORE observation and do not advertise it as executable-game survival.

The newly preserved obstruction root provides a cheap compatibility diagnostic:
generic Rook topology admits an a7-to-f7 edge with a clear ray, but actual own
Pe7 blocks that ray. Its full root public action table cannot contain Ra7xf7.
This is not a new path experiment or proof that all projected graphs are wrong;
it shows why a union-topology one-hop witness cannot be used as a fixed-context
contact time. A no-background contact prior is another declared context law,
not an estimate of this blocked state. Support/source sampling must be common
across modes and complete, retaining dead-rank, nifu, promotion/drop/typed-target
unknowns rather than picking a favorable location for each queried piece.
