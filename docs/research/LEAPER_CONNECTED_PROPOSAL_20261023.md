## Fixed scope and counting units

The original experiment uses eight uniform controls drawn FIRST from 310
remaining metadata-exposed codes, then eight disjoint draws from the eligible
conditional pool. Eligibility means both empty 4x4 movement graphs are connected,
sum of their mean degrees is in [6,12], and
`min(mean_degree_A,mean_degree_B)/max(...) >= 1/2`.
This is a balance between type means, not a per-square minimum-degree condition.
All 310 stored feature booleans match that definition. Uniform controls may also
be eligible; this is not a connected-versus-disconnected factorial.

Full inputs retain K+A+B per side, capture removal, no promotion/drop, rule/caller
clock 128 and repetition-four. This is explicit prototype scope; the generic
long-term domain still includes promotion, drops, auxiliary state and history.
Static AlphaBeta uses node512/maxdepth64/q0/check-hard-depth8. Players have fresh
TTs per game and retain them within that game; disk cache is off. FLOOR chooses
the first immediate winning child, otherwise a uniform canonical-legal index.
Both roles are included. Complete rules/profiles/records, source, controller
seeds, actual work and UNKNOWN cells are in the technical packet.

There are **896 planned slots, 894 retained execution records, 893 known
outcomes and three UNKNOWN**. Of the records, 870 contain new controller turns;
