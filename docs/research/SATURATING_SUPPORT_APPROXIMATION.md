# Cheap saturating-support hypothesis and a changed-premise falsifier

2026-10-05, prospective construction. To avoid2^n expensive legal-game roots,
consider a required physical source s plus supports J, with a=F({s}) and
q_j=(F({s,j})-a)/(1-a) if a<1. Approximate the SAME source task by
G(S)=0 if s is absent; otherwise
G(S)=a+(1-a)*(1-product_{j in S intersect J}(1-q_j)).
This is an independently motivated redundant-aid approximation: at least one
support supplies the missing service, with explicitly independent latent aid.
It accounts for saturation that a linear independent-support sum misses.
It is NOT implied by real-game legal choices, physical monotonicity or Shapley
axioms. Negative q/out-of-range q or a=1 with negative support effects invalidate
this parameterization; do not clip. An a=1 monotone version needs no aid weights.

With P(t)=product_j(1-t*q_j), its random-order allocations are
phi_s=a+(1-a)*(1-integral_0^1 P(t)dt),
phi_j=(1-a)*q_j*integral_0^1 t*product_{k!=j}(1-t*q_k)dt.
These finite polynomial integrals avoid coalition enumeration ONCE the supplied
a,q are justified. For r certain interchangeable supports and a=0, source gets
r/(r+1), each support1/[r*(r+1)]; the total remains1. This recovers the earlier
replica toy without pretending exact linear inventory prices. Singleton/pair

legal-game evaluator or mode-complete vector follows automatically.
