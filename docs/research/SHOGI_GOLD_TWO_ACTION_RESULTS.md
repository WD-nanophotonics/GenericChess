## Native Pawn versus its promoted board mode

A further SOURCE coupling follows from the qualified grammar, without solving
the missing long-distance worlds. Any native-P source path can be followed by
an already-current-TP source in the SAME target/blocker world: before promotion,
every forward Pawn leap is a Gold leap; after promotion both use Gold. Choose
the same squares, which preserves compatibility with the passive background.
Promotion takes no separate action. If native P is unreachable this still
permits TP to be reachable; thus tau_TP<=tau_P world by world. This assumes the
declared board-only grammar and absorbing target removal, not full legality.

There are27176 direct-TP worlds which are not direct-P:32864-5688. In each,
TP contributes gamma while native P contributes at most gamma^2 (possibly0).
Other worlds have nonnegative difference by coupling, so

    w_TP - w_nativeP >= 27176*gamma*(1-gamma)/511920 >0.
