# Availability dispatch and quiet-q execution attribution

## Decision

Retain compile-owned drop/board classification as a small scheduling improvement.
Keep the current legality, terminal authority, traversal, q budgets and UI branch.
Defer both the immediate single-child handoff and the private typed-token memo:
the former has zero immediately reusable children in the measured current order;
the latter has mixed cost and no deeper completion in the declared time controls.
End this availability microdispatch round. The next useful question is execution
and completion cost on a selected ongoing caller, rather than another wrapper
around the full Native frontier or unchanged repeat of the availability assays.

This is finite development evidence. None of these results establishes playing
strength, WDL, a universal price vector or Native support for the full rule domain.

## Product change and semantics

CompiledSemanticRuleset derives a mapping from each pattern's immutable geometry
ID tuple to whether any referenced geometry is a drop. SemanticEngine reuses that
classification in ordinary candidate generation, S3 reply existence and legal
binding traversal. Current-state predicates, actor types, effects, S3/S4 checks,
checkpoint order and child execution still run normally. Missing metadata or a
foreign tuple uses the original geometry scan. dataclasses.replace rebuilds the
derived table. The table is outside the IR/fingerprint/payload/equality contract.

The initial private version keyed pattern object IDs. Review changed it to
geometry tuples before delivery; both versioned source/results are retained.
Only the private table is pickle-tested: the full compiled product already has
mappingproxy fields and no full-product pickle contract. Its rejected pickle
trial was an assay assumption, not a newly observed product serialization defect.

Fourteen product tests cover full children/frontiers on ten rule fixtures,
availability/reply polling and cancellation at first/middle/last callbacks,
replacement, missing/mixed geometry, table round trip and simultaneous rich-hand
mechanics. Final default active suite:2063passed, no failures/errors/skips.
An earlier default account-temporary-directory run had1961passes and101setup
PermissionErrors, with zero assertion failures. Fresh project basetemp gave
2062passes before the final table test and2063after it; no ACL was changed.
Sanitized test summaries retain that failure. Account-bearing raw logs/XML stay
ignored locally and are excluded from the archive and publication.
