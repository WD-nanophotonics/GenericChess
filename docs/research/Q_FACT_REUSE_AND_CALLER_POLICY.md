## Private candidate and provenance

The existing full transition computes its child's gave-check event AFTER all
semantic effects, auxiliary updates and S4 postconditions. For a successful
fresh edge whose event history is exact and length is parent+1, the event equals
the literal opponent-side check query. The candidate reads it at q entry and
classification instead of recomputing it. Imported roots/inexact event streams
keep the literal query. It also checks this cheap event before quiet-terminal
classification; all recursive q entries still adjudicate actual terminal before
WIN/neutral claims. If classification has already computed an actual terminal
and winner, they pass only to that immediate child call, after the normal budget
checkpoint. No state is changed between the observation and use.

This is local data flow, not a position cache: no facts survive a call, change
state identity, enter a TT or authorize bypassing required legality/history.
It does not promise identical allocation-failure opportunities or wall-time
cancellation schedules after avoiding duplicate operations.
