# Next constructor scope: native/current promotion closure in target-present cubes

Source inspection after native closure: SparseContactCubes already computes
quiet transitions into (base,current,promoted) profiles, but its profile closure
is local rather than exposed; the frozen native qualifier exposes ONLY
nonpromotable closure. TypedSparse binds geometry to current actor. Reusing the
whole helper without additional guards would not constitute generic admission.

Prospective changed interface: admit a nonempty profile family only after every
reachable current profile validates ordinary self movement/capture-to-target,
actor geometry binding and compiled inherited promotion masks. Explicitly expose
the FULL quiet-result profile closure to target-aware BFS, never requested roots
alone. Current/origin/promoted status remain in graph keys. Capture result mode
does not affect an absorbed first-hit reward; quiet result mode does affect
future movement. Optional alternatives union; forced promotion cannot retain
native quiet continuation. The target remains enemy and blocker own throughout.

Existing event helper resolves source guards using current type, not a general
physical origin/promoted predicate. Therefore initially reject all such typed,
owner/promoted-sensitive source guards, auxiliary/history/multi-source effects
and unsupported target-type guards, rather than silently erase them. NONE mode
is acceptable only if compiled metadata cannot inject promotion alternatives;
otherwise reject whole family before geometry observations. Keep separate
Western Pawn auxiliary reduction, drops and royal/history exclusions.

Before any complete population, freeze a tiny unnamed promotable family with
optional and forced destination strata and a promoted current having different
quiet/capture geometry. Compare every fixed-blocker/source/target distance
against an independently coded (square,current,promoted) coordinate BFS for
both owners, retaining ordered hashes and full semantic event memberships.
Include a NONE-promotion rejection and an origin/flag-guard rejection. Renaming
types must not affect algorithm/admission/counts. No old Shogi census rerun or
new human/goal labels. Same128 patterns/events/choices,5000 canonical candidates,
15sec cap per prospectively frozen small study; complete census only after the
new grammar qualification and independent cost feasibility are established.

This design does not yet admit a new constructor implementation or additional
Shogi coefficients. Its purpose is to remove the current name/fingerprint
specialization through falsifiable semantics, not repeat an already closed
numerical population or require universal WDL calibration.
