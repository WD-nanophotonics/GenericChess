## Uniformity and scope

For Chess, choose eight own Pawn squares uniformly from 48 interior-rank cells,
then eight enemy Pawn squares uniformly from the remaining 40. Each distinct
owner-labelled Pawn layout has probability 1/[C(48,8)C(40,8)]. There are exactly
29,019,905,518,636,890 such layouts. For Shogi, nine unpromoted Pawns of each
owner plus nifu force one Pawn of each owner on every file. Allowed own ranks
0..7 and enemy ranks 1..8 have 64 pairs minus 7 collisions, hence 57 pairs per
file and 57^9=6,351,461,955,384,057 full Pawn layouts. Independent uniform
file-pair draws assign each the same probability; no source is reserved.

The remaining 16 Chess / 22 Shogi tokens are placed by a uniform injection
into 48 / 63 free squares. Identical-type label permutations contribute the
same multiplicity to every physical layout. Combining that injection with the
uniform Pawn factors therefore gives a uniform distinct physical proposal
within the declared initial-inventory structural support. This is a counting
argument for the random-draw construction; one fixed-seed realization is not
an empirical proof of uniformity or strategic representativeness.

Whole-board rejection removes Shogi dead non-Pawn placements, checks on either
actual anchor, and terminal actual roots. No hypothetical type replacement is
tested. Rejection returns to the original proposal, never to a retained parent
background. Thus the accepted law is the proposal conditioned on this COMMON
predicate. A first admitted draw within a fixed proposal ceiling, conditional
on admission occurring, has that same conditioned law. Failure within the
ceiling is incomplete evidence, not an empty law or a zero task score.

History and auxiliary state are reset: empty hands, no Chess castling/en-passant
rights, acting owner zero and synthetic root history. Promoted and held types
are outside this law. Structural constraints, terminal conventions and reset
history are model scope; uniform placement does not establish reachability.

## Decision

Adopt this exact structural/whole-board proposal as an available explicit
joint-reference construction. Its two observed admissions show local proposal
feasibility only. Neither routine is installed in production; the old frozen
prototype remains reproducible. Do not compute a coefficient batch merely
because admission is fast, repeat the initial zero-score probes on these boards,
or claim typical full-reply cost from proposal cost.

Next predeclare a distinct deployment law with inventory variation and a
capability-count error baseline/acceptance margin before any numerical type
estimate. Coefficients must be frozen using reference evidence independently
of deployment labels. The initial-inventory joint law removes one compatibility
obstacle but does not prove transfer to altered inventories, promoted/hand
resources, strategic utility or human material values. Validation of the
material objective remains separate, with Xiangqi references sealed.
