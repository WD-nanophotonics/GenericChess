The offline binary scorer rejects fuzzy rule/history/mu joins and duplicate
votes. Known-only Brier is conditional on coverage; missing truth and abstentions
remain in conservative whole-denominator bounds. Equal-rule macro bounds avoid
weighting a rule merely because it generated more histories. Fixed confidence
thresholds report descriptive risk/coverage, not an IID guarantee.

For known y, loss is(p-y)^2. Unknown binary truth contributes between
min(p^2,(1-p)^2)and max(p^2,(1-p)^2); an absent prediction has unknown loss[0,1].
These are identification bounds on an unevaluated full score, not a proper
reward for abstaining or a training objective. Calibration is not identical to
sharpness, accuracy, game utility or rule quality. No scalar game-quality score.
