# Interventions and independent use after an observed negative marginal

2026-10-05. Source analysis/next design, no new game sample or scalar candidate.
The actual N/R/P obstruction task distinguishes two different interventions:
physical resource ABSENCE removes occupancy, attacks, blocking and capabilities;
permission to ACT preserves the existing board while disabling selected moves.

Under physical absence, adding Pe7 to NR lowers task1 to0. An inactive physical
piece can still change enemy options. A proof that 'more optional actions cannot
hurt' does not apply to physical pieces, so the saturation shortcut cannot use
it. Nor can one quietly teleport blockers or reset a played history per subset.
These mechanism roots explicitly use separate fresh hypothetical histories at
construction; they do not represent counterfactual edits of a historical game.
Any future actual-history intervention needs a defined consistent history/
rights/repetition law and independent validation before its F(S) is evaluated.

## A monotone capability game is possible but changes the question

Fix full physical occupancy and attack semantics. For one owner, allow only
actions by enabled resources; absent permission does NOT remove a piece or its
passive attacks. Adding permission can preserve every prior strategy and its
opponent reply tree, provided all non-resource rules/history/terminal semantics
are held fixed and disabled future actions are handled consistently. This
supports a monotone option-value game. No implementation is supplied here.

However Ra7's passive pin is already present even when Rook movement permission
is disabled. A source-drop/capture strategy can then work without enabling any
Rook move. Its incremental Rook capability credit is0 despite the empirically
essential PHYSICAL Rook. The narrower intervention loses exactly the passive
support contribution that motivated coalition research. It cannot serve as an
unqualified replacement physical-material oracle. Restoring occupancy/check
effects as additional players brings interference back; it is a new factorization,
not a theorem of free monotonicity. Keep this option-value direction distinct.

## Signed candidate use requires a prospectively qualified leaf interface

For a binary-task coalition, each exact physical-token allocation is in[-1,1],
since it averages differences of two[0,1] values. Thus a correctly token-weighted
mode prototype also lies in[-1,1] if the common law and counts are qualified.
The current raw H2 helper `material_interval_choice.py` intentionally accepts
only[0,2]; feeding it signed allocations, clipping negatives or labeling them
raw service would change the constructor. Keep that frozen helper unchanged.

A prospective signed leaf operator can instead use complete signed own0-minus-
own1 mode counts Phi and E=sum_m w_m*Phi_m/(N+1), w_m in[-1,1], where N is a
qualified bound on physical ordinary tokens over the declared rule scope.
Then |E|<=N/(N+1)<1 even for negative weights. Qualified terminal wins/losses
remain +/-1 and draws0; unresolved claims/RESTART/unsupported terminals remain
incomplete. A fixed rule-derived bound avoids normalizing by an uncertain
maximum coefficient. Whole-stock deficits, anchor exclusions and Shogi capture/
hand modes must be explicitly reconciled before claiming a particular N.

Complete child features, identities and all quiet/terminal choices are needed.
For coefficient intervals, evaluate the exact signed pair-difference bounds;
only a coefficient-insensitive canonical selection qualifies, with complete
coverage of every encountered mode. Coupled policy/context parameters can give
tighter joint margins than independent coefficient boxes, but their complete
uncertainty set must be declared BEFORE observations. Do not take a midpoint
or favorable lower point. Unit/zero baselines use the same complete children;
independent goal regret remains a SEPARATE validation quantity in[-1,1].

This is a prospective interface specification, not permission to run the
reserved use generator: no full Chess/control candidate or signed mode law is
frozen. A local negative Pawn allocation is not a negative global Pawn price.
The next useful construction should exploit explicitly declared rule/obstruction
predicates or signed dependence, with a common demand/background law and a
smallest new falsifier. Replacing physical material by pure move permissions or
fitting exposed obstruction coefficients would skip the missing motivation.
