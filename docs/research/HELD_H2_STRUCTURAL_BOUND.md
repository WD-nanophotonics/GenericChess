# Held H2 service: structural range before stochastic precision

2026-10-04. Post-publication research continuation, no new game samples.
Changed question: does the hand/drop contract give a sharper direct-service
bound without measuring extra paths or introducing a hand premium?

Start with a fixed own tag entirely held among n same-base anonymous tokens.
The first own action cannot earn capture reward. If it does not drop that base,
the tag stays held and the second own action also cannot earn capture reward:
a second-action drop is not simultaneously a capture. If it DOES drop that
base, exchangeability puts tag probability1/n on the dropped board piece.
The second own action can remove at most one ordinary enemy, so integrated
Y=r(actual first-cycle child)<=1/n, including opponent capture/terminal stops.
Still-held mass earns0 within this H2 window. Other own captures may increase
the held pool, but without an initial drop they cannot create tagged board
service in time. No own simultaneous multi-effect capture/drop is admitted.

For a fixed root with A complete choices and D same-base legal drops under
the declared uniform policy, v_hand<=D/(A*n). This is an upper bound, not a
positive lower bound, expected premium or fitted coefficient. Under any frozen
context law average that root bound. Conditional path precision has range1/n,
not the generic board-mode range2. DO NOT rescale hand values by this range:
all coefficients retain the same raw unit-service gauge.

Existing frozen full-resource hand/P root has n1, D5, A54, hence v<=5/54.
This reads only structural complete choice IDs; it does not rerun the exposed
path or estimate a population value. Its observed no-drop path gives0 and

service. Losing continuation or fewer captures can only lower that result.
