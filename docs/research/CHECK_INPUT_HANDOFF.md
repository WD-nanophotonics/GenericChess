# Optional Core child-check input handoff

Retain one explicit default-OFF Core child-check option, qualified through the
actual public player. It shares a complete state-only Native input with the
already-required readonly availability query. Two existing heavy mixed-q4
consumers save locally about1.5–5.1% whole-call time with identical full decisions
and non-time work. Fresh small-rule costs are mixed and all32 equal-time retained
decisions/horizons remain unchanged. No universal speed, strength, default/UI or
independent Native q4 claim follows.

The scope is the existing supported Native rule subset and finite tested cohorts.
The project target remains the complete generated domain including promotion,
drops, auxiliary state and related history. Unsupported Native providers retain
Core. No new kernel, Native ABI, evaluator, pruning, time policy or automatic
configuration selection is introduced.

## Public interface and authority

AlphaBetaPlayer appends keyword-only use_native_semantic_check=False and
check_provider=None. The generic readonly callback is
check_provider(position, side, checkpoint=...) -> bool | None. None declines
to Core; non-Boolean values raise TypeError and required failures propagate.
Core invokes it only for a mandatory nonpass child check. Pass responsibility
remains False and the existing frame-bound current-check reuse remains.

NativeSemanticLegalityProvider.in_check imports the entire immutable Position
(board/base/current/owner/promotion, complete hands and aux), at state-only ply0,
then calls the existing Native scalar query for the explicitly requested owner.
After the final checkpoint succeeds, it stores only (Position object, capsule)
in one current-thread input handoff. has_legal_action detaches and clears it
at ENTRY, before polling/source/short-cutoff qualification. Exact same object
can consume the capsule once; equal copied objects miss. Native availability
is still queried each time. This transport does not cache a Boolean, history,
terminal result, score, root output or search bound. Full frontiers retain their
separate actual-ply import and checked binding reconstruction.

History and actual-ply terminal precedence remain Core-owned. A history or
action-class terminal can bypass availability, leaving at most one input until
the next check replaces it or availability consumes it. That bounded input is
not a terminal/history cache and no Core lifecycle framework was added.

To request the measured combination:

    AlphaBetaPlayer(compiled,
        use_native_semantic_availability=True,
        use_native_semantic_check=True)

Use the existing matching evaluator/limits; the flags do not select evaluation,
q horizon or a stronger policy. Native check alone adds a second import and lost
cost in the private control. The ordinary complete player/UI defaults remain.
