# Pure-Leaper 神经主线：首轮实施与结果（2026-11-07）

本轮按用户启动的一小时手动研究及 Slack 六段方向推进。账本记录 60.635 分钟有效研究；未核验间隔、等待及交付行政时间未计入。当前主线是 Rule-Conditioned Pure-Leaper Neural Player，取代零碎搜索排序、时延观察及传统棋价试探。两个巡检继续暂停，未启动 AUX、worker 或定时器；产品引擎和 UI 未改动。

已提供两个独立入口：`scripts.leaper_neural_teacher` 使用现有 exact threshold solver、Core 合法动作和完整会话历史；`scripts.leaper_neural_model` 加载实际训练权重，输出 WDL softmax 和有界估值。教师不是新规则引擎；网络没有进入产品玩家。另测的无 TT、根值 interval-negamax 原型失败，保留来源，未替换教师。

网络是一个共享 DeepSets 位移编码器、两轮 relational GNN 和全局 value head，hidden=24，共 10,779 个参数。所有格子（包括空格）参与图。规则位移、anchor、owner、占据、关系和时钟作为输入，不用棋子名字、编号或棋盘尺寸专用权重。最小检查覆盖重命名/规则列表顺序不变性、4/5 棋盘和增加棋种后的同一参数结构、真实终局及 exact/UNKNOWN 边界。这些是结构可执行证据，不是未知规则估值正确的证据。

本轮使用 Python 3.12.14、torch 2.15.0+cpu，训练两 CPU 线程。Torch 是独立研究依赖，未加入产品运行依赖。设计参考 [Deep Sets](https://arxiv.org/abs/1703.06114)、[Graph Networks](https://arxiv.org/abs/1806.01261) 和 [Size Generalization](https://proceedings.mlr.press/v139/yehudai21a.html)；这些文献不证明本模型已取得迁移或棋力收益。

## 教师和 4×4 value

最初 4-ply 数据的 384 个 4×4 标签中有 364 DRAW，验证集只有 2 WIN、没有 LOSS。三个种子均未识别这两个胜局。这轮不能把接近全和棋的总体准确率当成功。

只延长权威时钟的 768 次教师比较显示：8-ply 可以提供更多胜负标签，16-ply 则大多在 1500 节点内 UNKNOWN。随后用新种子生成固定的 1536 个 4×4、512 个 5×5 输入，沿用原来的模型、损失、优化器和采样法，不补原试验。生成耗时 577.516 秒；三种子各 160 epochs，完整训练阶段含预处理 44.323 秒。

| 8-ply 标签 | LOSS | DRAW | WIN | UNKNOWN |
|---|---:|---:|---:|---:|
| 4×4，1536 输入 | 132 | 584 | 166 | 654 |
| 5×5，512 输入 | 12 | 91 | 7 | 402 |

只用 exact 4×4 训练；验证组按当前局面/剩余时钟的 D4、颜色归一化和重命名等价组在标签前划分。4×4 验证支持为 23 LOSS、115 DRAW、22 WIN。三个种子的平均平衡准确率为 **94.57%**，结构线性基线为 **89.28%**；胜负局准确率均值 **96.30%**，基线 **97.78%**。预定“平衡准确率领先至少 5 个百分点且胜负识别也改善”的合取门槛未通过。它表明有限域确实学到了一些 value 信息，同时不构成阶段 B 的完整验收。

未做任何 5×5 微调。已暴露开发集上的 mean-readout 零样本平衡准确率均值为 60.33%，胜负局准确率 43.86%；结构基线分别为 73.41%、84.21%。不解释为成功迁移，不启动 transfer/scratch 对照或实际玩家比赛。

训练采用逆类别频率加权交叉熵。softmax 是未经校准的模型估计，不能直接称为真实胜负概率；产品价值映射尚未验证。所有指标都条件于有限预算可证实的子集，UNKNOWN 的缺失不是随机的。

## 只改变一个因素的后续检查

原采样把 family、棋子数量和额外棋子的 owner 绑定在同一个 slot 周期。216 个新输入独立交叉这些因素，冻结网络后未显示在新组合上的明显崩溃，但只有 6 个 LOSS，不能证明跨组合泛化。旋转/反射完整棋谱后，2160 次 Core 重放和当前合法前沿对应；5×5 的 19 个胜负局中，每个种子仍有 7–12 个在全部八个方向均错。短时钟检查还发现两步即可决定的误判；因此没有用旋转增强或单纯加深网络掩盖失败。

在已暴露的 5×5 开发输入上，一次只把全局 readout 从 mean 改为 sum/16，三种子的胜负识别均改善，4×4 输出完全相同。但放大的是整个隐藏向量，不足以单独证明“棋理信号稀释”，也可能改变分类偏置。显式 size/坐标等单组输入扰动没有给出跨种子一致的替代解释；这些不完整张量只用于敏感性分析，不是合法新棋局或可部署输入。

于是预注册一次新起点 readout 对照：最多 2160 个 5×5 输入、1500 节点/输入、600 秒派发上限，同一权重、完整规则/历史及教师，只比较 mean 和 sum/16。到 600.319 秒停止：1692 返回，468 NOT_RUN，1290 UNKNOWN、376 DRAW、22 WIN、4 LOSS。**不补跑**。

| 402 个 exact 子集上的三种子均值 | mean | sum/16 | 结构基线 |
|---|---:|---:|---:|
| 平衡准确率 | 61.20% | 73.30% | 86.15% |
| 胜负局准确率 | 48.72% | 57.69% | 88.46% |
| Brier，越小越好 | 0.07669 | 0.08985 | 0.35735 |
| 交叉熵，越小越好 | 0.18644 | 0.24473 | 0.55086 |

该候选 **NO_GO / INCONCLUSIVE**：胜负支持 26 少于预定 30；平均胜负增益 8.97 个百分点低于预定 10；概率误差反而增大。按 root 分组、三种子取平均准确率的配对类别分层 bootstrap，胜负增益区间为约 [3.85,14.10] 个百分点；这不推翻预定门槛，也不覆盖 UNKNOWN 或未知规则的不确定性。

事后检查发现采样只排除了最近的 512 个 5×5 输入，遗漏了更早 clock8 数据，造成 slot 61、1549 两个等价输入重叠。原返回全部保留，没有剔除或替换；不能称整个面板完全未见。未来新取样必须一次排除所有已覆盖的相同完整任务等价组。此处的负面验收不靠删除重叠来修复。

## 求解器和数据来源的实际瓶颈

根 WDL interval-negamax 候选在 72 个固定上下文中只解出 12 个，现有教师解出 45 个；耗时 22.53 对 16.79 秒，零相互冲突的 exact 标签。候选没有沿用原 TT，动作顺序及节点记账也不同，所以这只能否定这一实现，不能否定“只证明根值”的思路。候选已停止，现有 exact 教师继续使用。

再以同一初始棋盘比较短跳法 mask3 和更广的普通跳法 mask23：两个 royal + 一个普通子，普通子 owner 均衡，双方初始均未被将军，两套规则都先通过 Core，8-ply、1500 节点不变。300.102 秒关闭，457 个起点返回、55 NOT_RUN。5×5 每臂 225 个输入中，短跳法仅 14 个 W/L，更广跳法 25 个（12 WIN、13 LOSS），低于预定 60 且每类至少 15。更广跳法的教师时间为 95.22 秒，短跳法 83.17 秒；更强覆盖也增加证明成本。可解的三子子集中没有 exact DRAW，不能据此当作完整 WDL 训练源。**数据来源门槛仍未通过，不训练新网络。**

从保存的结果作零新增求解分析：readout 面板 1290 个 UNKNOWN 中，有 **962 个已有一条被证明为 DRAW 的动作**。这已证明根值不败，但其他未解动作可能赢，故根值仍须标 UNKNOWN，不能标 DRAW。独立教师现在额外返回整数 `bounds`：exact WIN=[1,1]、DRAW=[0,0]、LOSS=[-1,-1]；上述 UNKNOWN=[0,1]；完全未知=[-1,1]。此字段只提取已有证据，不改求解、标签或训练目标；旧面板没有重新求解或补字段。

两条 5×5 证书路径进一步检验标签/视角/终局绑定：LOSS 示例在 8 步重放到 Core checkmate；WIN 示例在后续第三个查询遇到预算 UNKNOWN，保留为部分路径。单条路径不代替所有应手的证明；一次子查询 UNKNOWN 也不反证已取得的父节点证书。

当前网络没有读取全部重复历史。对于这些普通非零跳跃、永久移除捕获、无 pass、repetition_limit=3、全局 max_ply=8 的输入，重复局面至少相隔 4 ply，第三次最早在 ply8，不能在限步前另改 WDL；已用合法 8-ply Core 循环核对。这不能推广到更长时钟或复杂历史规则。

## 成本、入口和下一步

32 个独立固定上下文的 resident CPU 测量：4×4/5×5 的“Core 终局检查 + 构图 + batching + forward”中位数约 0.521/0.569 ms，重放另计。初始 64 次测量因 TorchVersion 序列化失败未保存数值，保持 UNKNOWN；没有拿后来的不同输入冒充补回。此测量不是整个 ABP choose_action 成本，也没有证明实际棋力。

可运行入口（需要安装适配 CPU 的 torch；不影响产品依赖）：

```powershell
python -m scripts.leaper_neural_teacher --input docs/research/data/leaper_neural_value8_20261107/example.json --nodes 1500
python -m scripts.leaper_neural_model --checkpoint docs/research/data/leaper_neural_value8_20261107/value4-seed0.pt --input docs/research/data/leaper_neural_value8_20261107/example.json
```

`data/leaper_neural_*` 保存各轮 plan、实际原始返回、训练权重和分析。`.jsonl.gz` 为对应原始 JSONL 的无损压缩；若重做读取纯 JSONL 的数据分析，先用 gzip 解压出同名 `.jsonl`。已关闭 producer 不重跑补槽。`tests/development/test_leaper_neural.py` 为最小结构及真值边界检查。

下一问题改为：**能否复用现有 threshold predicate 的完整语义、TT 和动作顺序，仅把证明目标改为根 WDL，取得更好的教师标签/总成本？** 大量 [0,1] 根表明“不败证据已取得、胜负分类仍未完成”，比继续加模型或漫无目的增加规则更直接。先设计一个保持其他因素不变的小比较；不采用已经失败的无 TT 原型，不把部分信息伪作 exact 标签，不改网络/损失/产品默认。4×4 独立 value 验收后才进入正式 4→5 transfer/scratch；固定 ABP 实战和专用玩家搜索器仍在后续阶段。
