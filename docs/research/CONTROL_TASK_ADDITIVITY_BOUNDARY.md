# Task success is not an additive material price

2026-10-04. Source-derived implication of the actual held-L certificate and
the conditional exchangeability extension; no additional samples or labels.
Keep the same designated Pawn e6, two-own-turn horizon and sparse far-King
geometry. Let F(n) be optimal success using ANY of n own held native Lances,
with source custody at endpoint. F(0)=0 by absence of a source. F(1)=1 is
actually certified. F(2)=1 follows the same e4 strategy: one ordinary Lance
is deployed and succeeds, while the other stays optional. Binary range gives
the upper bound1. The n=2 argument is conditional rule derivation, not a run.

If one attributes the task to a particular anonymous physical Lance, its
public-information value is1/n for n=1 or2. The same public e4 strategy works
for each identity conditional on that identity being selected by the drop;
only one can be selected and complete. Here the sum n*(1/n)=1 agrees with
pooled task success. This is a joint identity partition for this one task,
not a general license to sum independently optimized hidden-world values.

No constant positive held-L coefficient c can represent all three values
F(n)=n*c with a fixed zero-resource baseline: F(1)=1 forces c=1, while F(2)=1
then contradicts2*c=2. Letting c depend on n recovers this task but gives an
inventory-dependent coefficient, not the proposed static mode-only vector.
An arbitrary fixed background offset is excluded by the explicit F(0)=0
deprivation contrast. This is NOT an impossibility theorem for useful static
material priors: that objective is approximate leaf utility, not exact binary
success for one fixed target. It is a limit on this particular calibration.

The obstruction has an operational cause: one target and one preparation
window saturate demand; a second optional source cannot make success exceed1.
Normalizing by target count merely moves the saturation scale. Rewarding
several targets, longer windows or more contexts changes the estimand and must
be independently justified and frozen before observation; it cannot be chosen
after seeing desired piece rankings. Even then, exact resource additivity is
an additional claim, not a consequence of max/min control.

Next useful question: can a task ensemble be motivated by the intended leaf
decision and yield an explicitly approximate resource marginal under limited
cost? Separate that construction question from independent search/goal use
validation. Do not demand universal additivity or WDL calibration before
exploration, and do not silently treat this successful binary witness as an
admitted intrinsic coefficient.
