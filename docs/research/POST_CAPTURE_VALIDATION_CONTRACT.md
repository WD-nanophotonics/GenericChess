# Independent post-capture capability-count validation contract

Base: 11bdbc1aca3d874e7938246b934b397c952fa997. Freeze this intended use
before numerical coefficients or deployment task labels. This is a narrow
board-actor capability test, not full material/WDL/search validation.

Reference: the already declared unchanged-inventory physical law Q. For each
current ordinary board type, v_t is its actual uniformly marked actor's mean
of the unchanged optimal-first-action/adversarial-reply exchange task. Freeze
any finite reference sample, all coverage, raw v and hashes before deployment
labels. No fitting to labels, human values or post-result type exceptions.

Deployment: for each actual initial own ordinary victim type t, draw a fresh
whole board from Q with independent seeds, reset the synthetic parent to owner
1 to move, and exhaust its legal actions. Condition the parent on at least one
legal capture of an existing owner-0 type-t actor with an ongoing successor.
Select such a unique physical capture uniformly. Its ACTUAL child has owner 0
to move; preserve board, hands, auxiliary state, repetition/history and any
check. Every victim type is an equal-mass diagnostic stratum. This measures
balanced inventory-transfer sensitivity, not strategic visitation frequencies.
This is a declared different law, not a context-preserving deletion intervention.
If a stratum cannot be produced within a separately frozen budget, it is
incomplete; never drop/renormalize it, replace a type or use an artificial removal.

Target Y(c): number of existing own ordinary BOARD actors whose complete legal
first-action/adversarial-reply task succeeds from this ongoing post-capture
state. Checked roots require legal evasions. Opponent replies include all legal
hand drops, promotions and terminal outcomes. Owner-0 hand actors are outside
this narrow target; after one owner-1 capture from the empty-hand reference,
owner 0 still has no hand tokens. Hand contributions for a full material prior
remain a distinct unsupported extension. No terminal root is silently scored
as zero: this deployment explicitly conditions on ongoing successors.

Predictor h_v(c)=sum_t N_t(c)v_t, using raw [0,1] task means, not max-gauged
material coefficients. Two frozen baselines are h_0=0 and h_const=sum_t n_t v_t,
where n_t is actual INITIAL own board count and the constant is derived only
from the reference. Use unnormalized squared count error L(h)=(Y-h)^2.

For a fully frozen finite diagnostic corpus, require R(h_v)<=0.9*R(h_0) AND
R(h_v)<=0.9*R(h_const), with positive baseline risks and nonzero reference
signal. Ten-percent improvement is an explicit engineering usefulness margin,
chosen before labels, not a rule consequence or a material-reference threshold.
Zero baseline risk, all-zero reference or incomplete coverage means this test
cannot qualify a useful nontrivial prior. Do not tune the margin or vector.
Passing a finite corpus supports that corpus only; population claims require
separate uncertainty/coverage analysis. Outcome/material benchmark gates remain
unchanged, and Xiangqi human values stay sealed.
