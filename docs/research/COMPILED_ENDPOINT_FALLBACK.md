The bounded prefix-free schedule is now integrated in the compiled ruleset only
when the existing 65,536-row incoming index is absent. Small indexed rules retain
their original path. A schedule exceeding 262,144 rows declines to the complete
reference executor. These are metadata bounds, not rule-domain exclusions.
Native's existing <=16-board range, evaluator/search/UI defaults and full
promotion/drop/auxiliary/history semantics remain unchanged.

The new private derived field is init=False, repr=False and compare=False.
dataclasses.replace rebuilds it from IR; it does not enter IR serialization or
fingerprints. Entries retain original rank, pattern, geometry and zero-based
endpoint, including min_steps and duplicate occurrences. Actual owner/current
type selects sources; the original Piece supplies base/current/owner to the
unchanged binding, path and guard checks. Ray prefixes are rebuilt only for
selected actual rows; leap prefixes remain empty. There is no state/history/
score cache, registry or new public search option.
