## Decision and semantic boundary

The predicate is existential over valid `(source, pattern, geometry, target)`
tuples. Every retained tuple applies exactly the same current-type membership,
atom-source compatibility, path/minimum-step predicate, state guard and slot
guard. Their functions are read-only; changing tuple order changes neither
truth nor required identity/transition error propagation. Returning true may
find a different first witness. False from one source remains continuation.

Pseudo-attack is a capture-eligible pattern relation, including empty and friendly
occupied target squares. It does not require a currently capturable enemy on the
target. The separate action-delivers-check witness keeps its own `target_ok`
and selected actor semantics. They must not be merged into scalar attack.
