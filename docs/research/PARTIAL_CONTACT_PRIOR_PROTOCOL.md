# Shared-duration partial-contact prior interface

New constructor/consumer, frozen2026-10-06 before algebra/benchmark. It uses
ONLY independently qualified uniform-world CDFs in diagnostic_duration_order
and leaves H tail an interval. No compiled full H histogram, graph query,
human holdout, official game/deployment or pricing calibration.

Input domain: total positive integer; same horizon keys1..17/infinity for
each virtual ordinary mode R/C/S/E/A/H; integer nondecreasing CDF lower/upper
counts between0 and total. R must be exact and positive at every positive
horizon, and its lower CDF dominates all other upper CDFs. 'infinity' denotes
the finite contact limit, not permitting unreachable pieces to capture.
H partial tail uncertainty is epistemic; no chosen midpoint/point coefficient.

Common duration masses on0,1..17,infinity, exact nonnegative rationals sum1;
at least positive mass outside0. Values>=17 can be folded into infinity ONLY
for this five-exact/partial-H interface, whose bounds are constant thereafter;
this is NOT full-H tail equivalence. Input is an explicit caller assumption,
not a distribution inferred from rules or selected by validation outcomes.
Contact raw=[sum p_n F_lower(n),sum p_n F_upper(n)]/total. Normalize every
mode by the SAME exact R raw value, retain H interval. No held-state premium,
physical profile or owner/royal-safety inference.

For signed inventory differences d_mode, same-duration/uncertainty comparison
uses sum d_mode*F_mode(n) with H endpoint selected by SIGN OF DIFFERENCE,
not subtracting independent position boxes. Thus common H cancels exactly.
For each deterministic positive duration h, numerator interval divided by
exact F_R(h) bounds normalized difference. Every common arbitrary duration
is an R-contact-weighted convex mixture of these ratios: universal lower is
their minimum and upper their maximum. This is a conservative certificate
for partial H CDFs; it is not claiming every interval corner is realizable.
Positive lower proves strict static order for all such durations; zero lower
only weak order. Negative lower means unproved, never automatic opposite.
No terminal or official goal ordering is inferred from static inventory.
