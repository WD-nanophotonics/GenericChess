# Pure-Rule Metamorphic Checks: Monotonicity Boundaries

**Classification:** `CAUSAL_DIAGNOSTIC`. **Unknown:** which monotonic claims follow from rule semantics alone, and which add a context or utility assumption? **Smallest observation:** compare finite synthetic transition graphs before and after one controlled rule change. Full games are unnecessary because the question is about exact strategy-set inclusion and terminal outcomes, not playing strength.

| Claim | What is provable, under which assumptions | Minimal synthetic evidence / counterexample | Does it constrain a type scalar? |
|---|---|---|---|
| **A rule-preserving symmetry preserves value.** | If a bijection maps every state, legal action, transition, and terminal payoff to its counterpart, exact minimax W/D/L is invariant. This is graph isomorphism, not a preference assumption. | A two-cell board with two mirrored states and mirrored legal edges has identical terminal labels and therefore identical values. Break one mirrored edge and the guarantee no longer applies. | Only equality across isomorphic encodings. It gives no order or scale between piece types. |
| **Adding an optional action cannot hurt its chooser.** | In a finite zero-sum game with fixed payoffs, if the transformed game preserves every old action and continuation exactly and only adds an optional action to that player's strategy set, the player's minimax value is weakly non-decreasing. At a single maximizing node this is max(A union {x}) >= max(A). | One node has a single move to Draw (0); the extension adds another move to Draw (0). The value stays 0. Replacing the added edge with Win raises it to 1. Thus the theorem is weak and does not imply a strict gain. | A context-specific inequality only. The all-Draw example rules out inferring a strictly positive material increment from option count alone. |
| **More mobility/reachability makes a type better in every context.** | Not generally provable. It reduces to the previous theorem only when the change is a pure strategy-set superset for the same player, with all old continuations and opponent choices unchanged. A changed RuleSet may alter exposure, replies, terminal conditions, or who can use the new edge. | Two contexts and two types suffice. In context 1, a fallback is Draw, type A's extra edge is Win, and B's is Draw: A outranks B. In context 2, A's edge is Draw and B's is Win: B outranks A. These are finite RuleSets with identical terminal utilities; only the legal transition edges differ by context. | No context-independent ordering follows. Selecting an aggregate requires a justified context comparison or distribution, which rule reachability alone does not provide. This agrees with the recorded context-reversing simulation-dominance result in `CURRENT_MAINLINE.md`. |
| **Capture, promotion, or re-entry has a fixed positive material effect.** | No such sign follows from the mechanic's name. The optional-action theorem applies only if the mechanic literally adds an optional strategy while preserving all existing consequences. A capture/promotion rule that changes transitions or the opponent's replies fails that premise. | In the two-context graph above, make the newly reachable edge represent capture in one context and promotion in another; the same terminal labels still yield a Win in one and only Draw in the other. A separate all-Draw graph makes either rule change value-neutral. | No fixed sign or magnitude. A value per type would need a mapping from heterogeneous context outcomes to one cardinal unit; a frequency-weighted mapping additionally needs a context distribution. |

These are candidate contracts for pure-rule metamorphic testing, not results from a new test run. A safe test can assert symmetry equality and weak minimax monotonicity only after checking the stated graph-preservation preconditions. It must not turn option counts, witness counts, or selected contexts into weights. The current project evidence supports context-indexed/ordinal relations and their reversals; it does not supply a rule-only scalarization. No formula, human value, Xiangqi material value, game, Arena, or Heavy is used here.
