# Cheap capture metadata admission without another tree

Freeze before compilation. New research helper builds a per-pattern capture
bit from the public compiled IR. A legal action with an explicit remove
effect whose owner is opponent must remove a real opponent victim: executor
rejects absent victims and wrong owners. Native Chess has no spawning,
hand transfers, self removals or owner-any removals. Admit only this narrow
effect vocabulary and exact native fingerprint; reject all other profiles.
Never infer capture from debug pattern names, destination occupancy or Pawn
names. A bit does not identify victim value/square or certify action legality.

One compilation; zero transitions/runtime/source pushes. Compare all31 saved
full-history root pattern IDs against independently verified capture flags
from chess_qsearch_ep_20261006.json, retaining legal-only provenance. Pattern
IDs are the first field of the saved native strings, whose three-field shape
must be checked. No unvalidated serialized action is made legal by this hint.
5000 term/15sec cap, no tree retry, source downloads or production mutation.
Actual metadata-adapted qsearch, generic promotion/drop/removal scope and
capture ordering value remain future work; equality of flags is not strength.
