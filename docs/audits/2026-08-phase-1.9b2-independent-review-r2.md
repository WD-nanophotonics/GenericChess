# Phase 1.9B-2 Independent Review R2

Reviewed:
- specification branch: `3e214840217de475f1e21ca0256619c30ee5c71f`
- implementation: `3f3affd0760a1bdee663885ca1050c0b7c942860`

R1 fixes are materially present in source. R2 records the next set of
source-confirmed gaps exposed by integrating the semantic executor into the
public Core lifecycle.

Current verdict:

`REFERENCE_EXECUTOR_REQUIRES_REVISION`

## R2-01 — Public action projection destroys semantic pattern identity

Internal `SemanticAction` carries `pattern_id`, but `semantic_public_actions`
projects it to legacy `BoardMove` / `DropMove`, which do not carry pattern
identity. `semantic_action_for` then reconstructs candidates and returns
`candidates[0]`.

Two normalized patterns may legitimately produce the same source/target and
promotion choice while having different effects.

Required:
- legacy `BoardMove` and `DropMove` remain unchanged;
- semantic public actions preserve exact `pattern_id`, `geometry_id`,
  actor/drop type and ordinary move/drop coordinates;
- semantically different bindings with identical visible coordinates remain
  different public actions;
- Core action dict round-trip preserves semantic identity;
- Session/GameRecord semantic schema may remain deferred, but must fail
  explicitly rather than silently reinterpret a semantic action.

## R2-02 — Runtime binding does not contain geometry identity

`SemanticAction` has no `geometry_id`. Legal generation loops all geometry ids,
but `_transition` later calls `_path_for` and takes the first geometry whose
target matches. If two geometries reach the same target through different
paths, legality and execution may use different paths.

Required:
- runtime binding contains exact `geometry_id`;
- exact candidate path comes from that geometry only;
- public semantic action preserves geometry identity;
- transition never rescans geometries and chooses a first match.

## R2-03 — Semantic position identity hashes sparse representation, not logical aux state

`semantic_position_key` hashes raw `Position.aux_state`. An omitted slot means
its compiled initial/default value during execution, yet an explicitly stored
copy of that same default hashes differently.

Required: repetition identity hashes logical auxiliary state; absent/default
and explicit/default are identical.

## R2-04 — Aux physical keys are not a single sortable type

Current GLOBAL values use integer keys while PER_OWNER values use tuple keys.
`_transition` sorts `aux.items()`. A ruleset with both scopes can raise
`TypeError`.

Required canonical physical key:
- `AuxKey = (slot_id, owner_tag)`;
- GLOBAL -> owner_tag `-1`;
- PER_OWNER -> owner_tag `0|1`;
- semantic children emit sorted canonical keys.

## R2-05 — PER_OWNER expire_next_turn resets the wrong instance

Current transition resets only `_aux_key(slot, side_to_move)`. A value created
by owner 0 therefore survives owner 1's next transition.

Frozen lifecycle:
- before current action aux-setting effects, reset every logical instance of
  every `expire_next_turn` slot to initial;
- GLOBAL once; PER_OWNER both owners;
- current action effects may then set the appropriate owner instance.

## R2-06 — AUX_SLOT_SQUARE bypasses logical scope/default resolution

Raw square-ref resolution cannot correctly resolve PER_OWNER canonical keys or
omitted compiled defaults.

Required:
- AUX_SLOT_SQUARE uses the canonical aux resolver;
- PER_OWNER selects the binding/perspective owner;
- implicit defaults resolve like explicit defaults;
- effect operands are bound from pre-action state.

## R2-07 — Semantic public paths do not enforce ruleset fingerprint identity

Legacy Core guarantees mismatched position/ruleset raises
`RuleSetMismatchError`. Semantic public dispatch currently enters the executor
without the equivalent check.

Required: every public semantic Core entry validates fingerprint identity.

## R2-08 — public legal_successors is still legacy-only

`transition.legal_successors` still calls legacy move generation and transition.

Required:
- semantic compiled rulesets are supported additively;
- returned actions equal public `legal_actions`;
- every child equals public `apply_action`;
- terminal state returns empty;
- legacy path remains unchanged.

## R2-09 — pseudo-attack still has multi-type geometry cross-product

R1 added type↔legacy-geometry filtering to legal `_board_actions`, but
`is_square_attacked` lacks the same filter.

Required: pseudo-attack uses the same exact type↔geometry compatibility.

## R2-10 — pseudo-attack ignores S1 guards and uses side_to_move as owner perspective

Attack currently evaluates capture geometry/path only, ignoring state/slot
guards. Path owner filters compare with `position.side_to_move`, not the
attacking owner.

Required:
- pseudo-attack is S0+S1 capture eligibility;
- state guards and slot guards participate;
- SELF/OPPONENT are relative to attacker/perspective owner;
- no full legal recursion and no S3 own-anchor safety.

## R2-11 — TypeRef is not centrally actor-bound in effects

R1 fixed state-query binding, but effects still resolve action-relative TypeRefs
from the manipulated piece or from no actor.

Required: one immutable pre-action binding context contains at least pattern,
geometry, actor owner/type/base/current, source, target, promotion choice and
exact path. All TypeRef/SquareRef/guard/effect resolution consumes it.
Query/effect target pieces never redefine ACTION_BASE/CURRENT.

## R2-12 — remove effect permits empty/wrong victims

`remove` currently succeeds on an empty referenced square and does not enforce
`piece_owner` or `piece_type_ref`.

Required:
- remove requires occupant;
- owner/type binding enforced;
- legacy capture lowering explicitly uses victim owner OPPONENT;
- EP fixture explicitly uses victim owner OPPONENT and type ACTION_BASE;
- anchor prohibition remains.

## R2-13 — move/shift/place can overwrite pieces implicitly

Effects assign destination without requiring it to be empty after prior
effects.

Required:
- move/shift destination empty at execution;
- place destination empty;
- capture/removal is an explicit earlier effect;
- compound effects cannot silently delete a third piece.

## Merge gate

1. R0 + R1 + R2 frozen tests pass unchanged;
2. semantic public actions are lossless bindings;
3. aux state/repetition identity are canonical logical state;
4. mismatch and `legal_successors` are closed;
5. attack/legal generation share exact S0/S1 binding semantics;
6. effects obey explicit occupancy/owner/type contracts;
7. legacy differential remains green;
8. Native/Search/Learner remain frozen;
9. S4 remains fail-closed.
