# Phase 1.9B-3 Specification R2 — Retire Superseded B-2 S4 Capability Gate

Status: frozen specification supersession.

Baseline specification R1:

`f3356c7c60802ae6d8ace480478ead3beaf2b306`

## Finding

Phase 1.9B-2 intentionally failed closed for every semantic ruleset containing
S4 postconditions because the Python reference executor only implemented
S0-S3. Two frozen B-2 tests encoded that temporary phase boundary:

- `test_s4_semantic_rules_remain_fail_closed_in_b2`
- `test_s4_ruleset_is_rejected_as_a_whole_not_partially_executed`

Those tests correctly protected B-2, but they are not timeless semantic
requirements.

ADR-016 §13 freezes the Phase 1.9B-3 capability transition: supported S0-S4
rulesets using the existing closed postcondition set
(`opponent_checked`, `no_legal_reply(max_stratum<=S3)`) must receive
`new_ir_core_executable = True`.

Therefore the old B-2 `False` capability assertions and B-3 `True` capability
contract cannot coexist for the same supported ruleset.

## R2 supersession

R2 retires only those two phase-local B-2 S4 fail-closed assertions.

All substantive B-2 correctness contracts remain frozen, including ruleset
fingerprint precedence, public semantic action identity, exact geometry/runtime
binding, canonical aux state, transition event semantics, pseudo-attack
semantics, effect/invariant execution, legacy differential behavior, and
unsupported/invalid semantics remaining fail-closed.

The two historical tests are rewritten as continuity tests for the B-3
transition:

- the same supported `uchifuzume_ruleset()` still reports
  `contains_postcondition=True`;
- after B-3 it must report `new_ir_core_executable=True`;
- `SemanticEngine(compiled)` must construct rather than rejecting the whole
  supported S4 ruleset.

Unsupported postcondition kinds and invalid probe strata remain fail-closed
through the B-3 specification tests.

## Test-gate interpretation

"R0/R1/R2/R3 unchanged and green" means the substantive correctness contracts
remain unchanged. It does not preserve an earlier phase's explicit temporary
capability boundary after the later phase implements that missing capability.

The Phase 1.9B-3 task is updated to state this exception explicitly.

## Semantic contract change

No ADR-016 S4 semantics change.

This R2 changes only the phase-boundary interpretation of two historical B-2
capability tests so the frozen test suite can represent the B-2 → B-3
capability transition coherently.
