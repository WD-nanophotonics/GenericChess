# Task029: entered attempts versus publications
Three tiny controls use exact frozen primary observer functions. Normal returns a child with1copy/1freeze/1transition. A single MemoryError before saved init returns no child but counts1copy/1transition. A single MemoryError before saved freeze returns no child but counts1copy/1freeze/1transition.
Each fault reaches once, original exception object propagates, full parent is unchanged, trial row records exception. No timing reported and no primary caller rerun.
This concretely bounds the observer vocabulary: finally counters are entered method attempts. It does not show a fault in the primary's completed record, invalidate its accepted/rejected outcome rows or establish natural failure frequency.
