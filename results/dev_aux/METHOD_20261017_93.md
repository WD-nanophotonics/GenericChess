# Segment93: paid generic TD / mean TreeStrap comparison

The user-directed TD/search-bootstrap route remains primary. The old terminal-WDL
selector is a historical paid control, not the only permitted training feedback.
This experiment changes the generic learning update while keeping the same six
signed material channels, rules, initial seeds, deployment search and total paid
node ceiling. It is an operational learner comparison, not a pure ablation of
information quantity, a faithful historical replication, or a price deployment.

## Existing-data role diagnostic

Task2545 reuses ALL task2539 WDL TRAIN games and complete candidate queries.
Each current/proposal block freezes theta across both candidate roles and four
paired root families. No search is rerun and no computed update is applied.
For predictions v_i and recorded PV semi-gradients g_i, use actual candidate-clock
residuals delta_i = v_(i+1)-v_i, plus actual terminal z-v_last when known. UNKNOWN
omits only the invented terminal residual; valid prior bootstrap terms remain.
The episode update is eta times sum_i g_i sum_(j>=i) lambda^(j-i) delta_j.
Independent forward eligibility, backward convolution and frozen-target central
finite differences are compared for every game. A fixed-target loss defines only
a local surrogate; this is not an actual WDL gradient.

Report role means d0,d1, norms, within-role vector variability, zero vectors,
no-observation episodes and UNKNOWN. The original complete-block mixture uses
one-half each role; a separate supplement uses actual task2539 TD game-role
frequencies for the same rule/initial. Check d0 dot d and d1 dot d, not cosine
alone. These WDL trajectories and theta are not the actual TD visitation process.
Repeated theta/current/proposal blocks and four-family cells are correlated;
cell counts do not supply an independent population sample or causal color test.
The same full candidate-turn state cannot have opposite learner roles. No role
feature, sign flip, new self-play regime or price selection follows from a conflict.

## New paid learning comparison

Tasks2546/47 freeze all four previously generated 4x4 rules, all four initial
seeds, uniform fixed opponent, prefix4 legal random exploration, plain full-width
D2 path-seeded coefficient-independent ordering, 128 played-ply game horizon,
4096 nodes / 2 seconds per query, and 200000 ALL paid visited nodes per arm.
There are32 arms / 6.4M nodes. Opponent, failed and small-tail work all count.
Roots use NEW221000+ game-family identifiers; no terminal or outcome filtering.
GameSession executes actual legal moves, promotion, drops, auxiliary state and
history in these four rules. Non-scoring terminals are rejected, never draws.
This is finite TRAIN-exposed rule support, not the complete generated-rule domain.

FreeModel has six unconstrained signed weights, initial board P=1 and other
coordinates sampled uniformly in [.5,1.5], tanh(raw/10), and no human target table.
P is FREE after initialization. This follows the recent paired free6 comparison;
no new normalization is applied. A fixed transform scale is not a fixed intrinsic
price scale, and stable/unique price ratios are not assumed.

TDLeafEpisode uses eta=.05/lambda=.95, candidate-only observations, white-oriented
predictions/gradients/outcomes, weights frozen per actual game, and a summed
eligibility update at game end. Zero terminal-PV gradients preserve earlier
eligibility; actual unknown game endings supply no fabricated terminal label.

The TreeStrap variant updates after each complete CANDIDATE search. For each
nonterminal interior node, compute pred=tanh(theta dot phi/10) and transform the
recorded lower/upper search bounds monotonically. Error is the nearest violated
bound minus pred, or zero inside the interval. The update is eta times the MEAN
of error times grad(pred) over the frozen query samples. All values/gradients are
computed before applying that update; the already chosen action is then executed.
A partial root search supplies NO descendant training batch. Static depth-zero
leaves have no interior sample. Every interior sample and its true bound type is
recorded; budget failure leaves the game UNKNOWN unless already actually terminal.

The same eta does not give the two algorithms the same effective step size.
Per-query MEAN versus per-game SUM, visited positions, target distributions and
number of played games differ. This is not evidence that extra tree nodes alone
caused any gain. Separate target-specific training losses must not be compared
as if they measured the same objective. Gross absolute non-draw-terminal-valued versus remaining-target credit
is diagnostic before cancellation, not causal contribution or actual reward.
Only exact +/-MATE targets identify non-draw terminal-valued search nodes.
A zero DRAW target cannot be separated from an ordinary material-zero target
using the stored interior fields; those zeros stay in the OTHER bucket.

## Primary sources and differences

[TreeStrap, Algorithms1/2 and sections3-6](https://papers.nips.cc/paper_files/paper/2009/file/389bc7bb1e1c2a5e7e147703232a88f6-Paper.pdf)
uses summed linear updates and one-sided alpha-beta targets. Our transformed mean,
few-feature, plain-D2, fixed-opponent variant is explicitly different. No paper
performance claim is transferred to these generated rules.

[TDLeaf, equations4/9 and section5](https://arxiv.org/pdf/cs/9901001)
links searched predictions to later feedback and includes external-opponent
training. That does not guarantee this fixed material representation, role mixing
or finite-budget regime converges or improves actual WDL.

Raw `query_updates` counts nonzero computed query gradients, which can differ from
stored floating-point coefficient changes. Information diagnostics report both;
closed-game `updates` counts actual before/after coefficient inequality. Large
query journals are publicly delivered as exact ZIP payloads rather than direct
Git blobs; only their three explicit paths are ignored in the working tree.
