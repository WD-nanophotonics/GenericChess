# Generic TD material learning curve: frozen method, segment90

The new mainline trains through search/temporal-difference signals and tests
strength with actual rule outcomes. The old terminal-WDL grid and WIN prover
remain historical controls; neither is a prerequisite here. This is a research
implementation on sidemission, with no Core/product/default/UI integration.

## Model and actual rule authority

Reuse Model/TDLeafEpisode/TrainingSearch from2492/2504 and the2511 non-scoring
guard. Full GameSession state and complete typed GameRecord history govern
legal actions, promotion, capture-to-hand, drops, repetition and terminals.
Only choices/execute helpers are used from the existing proof-module facade;
no WIN proof search, certificate, table lookup, special endgame policy or teacher
WDL is invoked. Python rule authority is shared, not an external engine.

The six material channels are board-current P/A/X and hand-base A/P/X. Kings
are excluded. Board-base identity, squares and auxiliary values are not additional
learned features; complete rule state is still retained by search. This is a
restricted material representation, not proof of feature sufficiency.

Prediction is tanh(theta dot phi / 10). The board-P coefficient is fixed +1;
other five coordinates start Uniform(.5,1.5) and remain free signed. Generated
P is not a Chess pawn. Fixed positive P excludes zero/negative P directions;
with fixed temperature10 it also restricts prediction amplitude and learning
dynamics. It is not merely choosing units, and10 is not a validated calibration.
No human values/order, SEE, material ordering, position terms or clipping are
introduced. Coefficients of different rules are not pooled by P/A/X spelling.

## Update and search

Both selfplay sides use the same model, frozen for one episode. Every halfply
has a player0-oriented selected-PV prediction v and its stored gradient g.
For the admitted predictions, the update is eta times sum_t(delta_t e_t), with
e_t = .95 e_(t-1) + g_t and eta=.05. Search targets and branch choices are held
fixed for this semi-gradient update. No differentiation through target/search
selection is claimed. A real terminal PV is a constant +/-1/0 and has zero own
gradient; earlier eligibility can still receive subsequent credit. An actual
terminal episode supplies its real final target. Censoring omits that artificial
final target only, retaining earlier valid search-bootstrap terms.

Plain full-width alpha-beta depth2, no qsearch/TT/pruning priors, uses coefficient-
independent SHA256(seed,fulltypedactionpath) shuffled order and strict-better ties.
4096nodes/2seconds per query; an incomplete query supplies neither action nor
training data. There is no shallow fallback. Halfply/shared-player0 credit and
constant eta/temperature are explicit variants, not a literal Beal-Smith or
KnightCap reproduction. Initial seed also influences TRAIN search ordering;
variation across seeds is not solely an initialization effect.
