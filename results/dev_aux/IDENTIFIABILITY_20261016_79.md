# What the price experiment can identify79

This is a conditional argument about the actual capture-only R1-vs-N2 assay,
not a theorem about all generated GenericChess rules or human piece values.

For a fixed root-side target, ownership cannot change and there is no promotion,
drop, auxiliary score, fractional feature or magnitude-dependent search heuristic.
Every nonterminal material leaf is either `r*x-n` or its negative, with
`r in {0,1}` and `n in {0,1,2}`. Actual terminal scores are0 and signed infinity.
Two such finite scores can exchange order only at `x=1` or `x=2` for positive x.
The complete positive parameter domain therefore has five comparison classes:
`(0,1)`, `{1}`, `(1,2)`, `{2}`, `(2,infinity)`.

Within an open class there is an order-preserving correspondence between ALL
possible leaf scores, fixing0 and the two infinities. Min/max and alpha-beta's
strict comparisons and cutoffs preserve this correspondence. With the same full
rule/history, fixed action ordering, fixed completed depth and deterministic node
budget, induction over the searched tree preserves chosen actions, cutoff
locations and work counts. The fixed low-inventory guide does not use x. Thus
more samples cannot identify a unique metric ratio inside such a class under
these assumptions. A wall-time interruption, different feature domain, numerical
rounding/overflow or magnitude-dependent pruning is outside this argument.

The original grid0.5/1/1.5/2/4 already represents all five classes. New3 is another
representative of the last class, not a new class or a scientifically chosen price.
The320 root and40 first-difference D3 qualifications corroborate selected actual
contexts; they are not an all-state engine verification. New767 actual games
show little separation between the two open cells and the boundary; old1
comparisons remain seed-sensitive. Neither identical few records nor intervals
containing zero prove policy equivalence or that all learning benefit is artifact.

For a future fixed finite linear feature domain, the analogous comparison
boundaries are `theta dot (f_i-f_j)=0`. This is a possible identifiability
limitation, not authority to truncate generic state/history or replace real W-L
with material labels. Broader inventories/mechanics or declared strategic
features can add distinct comparisons. The next useful study must change a
specific rule/distribution/strategy premise and retain real decision utility;
within-cell numeric refinement alone is not the next experiment.
