## Implementation

`scripts/generic_win_proof.py` supplies bounded iterative AND/OR proof trees;
`generic_win_proof_pn.py` is an optional best-first PN alternative. Both use the
complete rules runtime, every legal defense, actual rule terminals, full path
history and no material/tablebase hints. UNKNOWN never means draw. Independent
certificate verification and a rank-decreasing `StrategyCursor` ensure a
proved win is followed through both players' actual moves.

The research player reserves shared resources for proof/verification and falls
back to material alpha-beta or the existing mature engine. It exposes proof
rank and an optional state-only trigger; continuations outrank new-trigger
checks. Declaration choices and runtime-unsupported no-progress rules are
explicitly refused. Deadlines are cooperative, with actual elapsed time logged.
Usage, interfaces and limits: `docs/research/GENERIC_WIN_PROOF.md`.

calls**. Original H16 labels/scores remain unchanged. This is not an extension
