## Slot and query replay

- Bind each result slot and every query row to `(candidate_index, candidate_seed, root_family, learner_color, endpoint)`; reject duplicate, unplanned or cross-slot keys. The candidate index disambiguates family IDs shared by different generated rules.
- Load the rule JSON named by the frozen candidate index, compile it with the pinned engine path, replay the exact saved root `GameSession` record, and require the resulting full record to match the root pool.
- Require query ply indices to be contiguous exact integers; each `record_before` must equal the prior full-history state and `actor` must be an exact integer equal to the replayed side to move. Do not issue a query after an actual or non-scoring terminal. Reject JSON booleans masquerading as integers or numeric weights.
- Each query's node count must be a nonnegative integer no greater than `requested_nodes`; its request must equal `min(nodes_per_query, slot_cap - prior_slot_nodes)`. Sum query nodes and queries to the slot closure and result totals.
- A complete query must append exactly one legal action and replay to `record_after`. An incomplete query must append no action and leave the history unchanged. Search value/PV fields are not actual W/L/D labels.
- Require the selected model snapshot to match the bound initial vector or audited candidate model; require the opponent to match the fixed all-ones vector. Check that slot color, endpoint and family determine the expected parameters and node cap.
- Recompute `env.terminal()` from the fully replayed final history. `ACTUAL_TERMINAL` must match its actual W/L/D and learner-relative reward. Every non-scoring or nonterminal closure is UNKNOWN with no outcome/reward. A closure may not hide an actual scoring terminal.
- Closed result rows must have a complete, newline-terminated receipt. Queries with no slot closure are invalid for a graceful partial result; a hard-killed process without a final receipt is separately `NO_FINAL_RECEIPT` and is not analyzed as a closed run.
- Derive missing slots as the exact planned universe minus closed rows. Keep completed UNKNOWN rows separate from absent slots and calculate bounds over all 512 planned pairs.
