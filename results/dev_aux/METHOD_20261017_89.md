# TD training exposure comparison — registered89

The user-selected incremental-learning route remains the main experiment.
This study changes only the legal random TRAIN prefix length,16 versus64 plies.
Both arms use the SAME episode-frozen TDLeaf(lambda=.95,eta=.05), same pawn1
scale/tanh(raw/10), four random initializations, coefficient-independent path
ordering and plain complete D2 alpha-beta. It has no qsearch, SEE, material move
ordering, positional features, generic WIN prover or human-price fitting.

Each arm receives1.5M actual search nodes; there are eight arms/12M total.
The original aggregate2400-second TRAIN cap includes logging/updates/prefix
construction. Reaching it leaves partial/unstarted arms visible. Node work and
wall time are distinct; longer prefixes consume legal transition work outside
search nodes. Prefix seed111000+episode is shared across treatments and initial
weights, but later game counts and on-policy trajectories need not match.
Actual terminals reached during prefix generation remain included, never filtered
by win/loss or a learned price. All four initializations remain in every analysis. Their seed also determines
TRAIN search tie-ordering, so across-seed consistency includes BOTH initial-weight
and associated exploration variation; it does not isolate initialization alone.
The pre-query syntax error and corrected byte pins are separately preserved.

TD uses a white-oriented shared value and observes EACH HALF-PLY for both sides.
Lambda .95 therefore applies per half-ply; its eligibility decays .9025 over two
plies. This differs from an agent-turn sampling convention and is not made
equivalent merely by rescaling lambda, because intermediate observations differ.
The same convention is fixed in BOTH arms, so this does not change the contrast.
No adjustment to running weights/lambda/search or frozen caps.

TD observes selected search-leaf gradients and frozen values each ply, then
updates at the end of the episode. Terminal leaves are constants with zero NEW
gradient; earlier eligibilities can still receive credit. UNKNOWN omits an invented
final target and retains earlier valid bootstrap terms. Search resource failure
rejects that whole query. Complete records, used node/wall limits and reasons
are journaled. The independent audit uses a reverse future-error convolution,
separate from the learner's forward eligibility implementation.

Pre-fitness deployment:16 NEW legal-prefix families96000..96015, both colors,
four initializations, initial/TD16/TD64 against uniform1 foe:384 games. A second
fixed random foe uses the first8 SAME families:192 games, not new independent
family evidence. Both use identical plain D2,8192 nodes/query,5seconds/query,
H512 and16 random prefix plies. Baseline is physically paid once per panel/foe.
All outcomes, UNKNOWN and cap-missing slots remain; unknown utility is[-1,1],
never a draw. Direct TD64-minus-TD16 cancels the shared initial baseline.
Descriptive family and crossed seed/family envelopes respect repeated families.
The random foe is fixed before outcomes and is not assumed stronger.

Consistency is descriptive: across ALL4initials at0/500k/1M/1.5M node snapshots,
report pairwise free-coordinate RMS distance and six pairwise material-order
agreement rates. Snapshots below intermediate thresholds use the last CLOSED
episode; the final point keeps valid earlier terms in a final censored episode.
No best checkpoint/price/seed selection. A rank or smaller distance is not
strength or a universal value ratio. TRAIN loss is moving on-policy TD loss,
not fixed validation error, and may change when starting distribution changes.
